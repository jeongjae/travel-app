## 구현과 추천 실행

`scripts/source-preflight.py`는 고정 commit·완전한 tree·파일 경로·Git blob 지문/크기·중복/링크를 검사한다. 선택 파일과 읽기 전용 checkout을 주면 원본을 실행하지 않고 Git blob SHA-1과 파일 SHA-256을 대조하고 다시 읽어 변경을 감지한다. 원본 내부에 보고서를 쓰는 경로도 거부한다. 모든 이행 판정은 처음에 unreviewed이며, 경로나 확장자로 자동 제외/이행 완료를 만들지 않는다.

전체 저장소를 자동 다운로드하거나 크기 한도를 늘리는 대신, 원천 전체 목록을 먼저 보존하고 실제 대표 2~3일의 필요한 관계·첨부를 선정하는 방안을 실행했다. 기존 neutral 어댑터를 실제 원천 전체 어댑터로 간주하지 않는다. 사용자 제품 정책의 새 합의가 아닌 작성자의 기술 판단이다.

```powershell
.venv/Scripts/python.exe scripts/source-preflight.py --tree local-data/p07/source-tree.json --expected-commit 35498adc6413dad45922f2dab87781afeb04d898 --output local-data/p07/preflight-report.json
# 실제 선택 목록/원본 checkout이 준비된 후에만:
.venv/Scripts/python.exe scripts/source-preflight.py --tree local-data/p07/source-tree.json --expected-commit 35498adc6413dad45922f2dab87781afeb04d898 --selection local-data/p07/selection.json --source-root local-data/p07/source --output local-data/p07/verified-report.json
```

두 번째 명령의 경로는 후속 실행 예시이며 실제 준비/실행한 파일로 보고하지 않는다.
