## 0. 사용자 결정(2026-11-03)

- **방문 기록 기본 동작: 한 번 누르면 바로 저장.** 사용자 답변: "한 번 누르면 바로 저장 (권장)". `방문 기록`을 누르면 현재 시각(기기 시계)·여행 시간대로 즉시 저장하고 토스트로 알린다. 시각·메모는 저장 뒤 `정정`으로 고친다.
- Q-U1에서 확정된 탐색 구조·활동 `⋯` 메뉴·날짜 띠는 유지한다.

## 1. 바꾸지 않는 것

저장 명령·스키마·`timeSpec`/`timeRange` 계약·백업 형식·검증 규칙. 아래는 전부 **기존 필드로 가능**함을 Codex가 확인했다:
- 시간대 기본값: `trip.defaultTimeZone`(`timeZoneStatus: 'confirmed'`일 때)
- 변경 이유: `ChangePlan.reason`(현재 `'사용자 일정 수정'` 고정)
- 종료 시각: `planItem.time.end`(`timeRangeSchema`, 종료<시작 검증 있음)
- 정정의 원본 보존 규칙(`field-rules.ts`)

## 2. 범위

### B1 활동 추가·일정 수정 폼 (`ContentApp.tsx`의 활동 편집기)
1. 칸 순서: **제목 → 장소 → 날짜 → 시각(선택) → 종료 시각(선택) → 변경 이유(수정 때만, 선택) → 메모**.
2. `발생 날짜`를 없앤다. 날짜는 `계획 날짜` 하나다(시각이 있으면 그 날짜로 `time.start.date`를 채운다).
3. `시각 정밀도` 선택 상자를 없앤다. 시각 칸이 비어 있으면 `unspecified`, 채우면 `local`. `원문 표현`·`정확한 시점`은 고급 접기(`자세히`) 안에 둔다. 기존 데이터의 `text`/`instant` 값은 접기에서 그대로 편집된다.
4. **시간대**: 여행에 확인된 시간대가 있으면 자동 사용하고 칸을 보이지 않는다(접기 안에 `시간대: Asia/Tokyo (여행 기본)` 표시와 변경 가능). 여행 시간대가 `unknown`이면 지금처럼 칸을 보이되 `IANA` 대신 `시간대 (예: Asia/Tokyo)`로 쓴다.
5. **종료 시각(CL-18)**: 선택 칸. 다음 날 00:30처럼 시작보다 이른 시각을 넣으면 "다음 날로 저장할까요?" 확인 뒤 `end.date`를 +1일로 저장. 타임라인에 `23:30 ~ 00:30 (다음 날)`로 표시.
6. **변경 이유(CL-17)**: 일정 수정 폼에만 선택 칸. 비우면 기존 문구 `'사용자 일정 수정'`. 숙박·이동 폼의 기존 이유 칸과 같은 모양.
7. 모바일 대화상자(B3): 저장·취소 버튼을 하단 고정(`position: sticky`), 폼 본문만 스크롤. 다른 모든 `Modal` 사용처에 같은 규칙.

### B2 실제 기록 (`Field.tsx`)
1. 카드 `방문 기록`: 즉시 저장(§0). 실패하면 기존 폼을 연다.
2. `⋯ → 건너뜀 기록`·`예정 외 활동 기록`·`정정`: 폼을 열되 B1과 같은 형식(`실행 결과 → 날짜 → 시각(선택) → 메모`). 날짜 기본값은 보고 있는 날짜, 시각 기본값은 현재 시각.
3. `시각 정밀도` 선택 상자는 접기 안으로. 기록에서 자주 쓰는 `날짜만 확인`은 시각 칸을 비우는 것으로 표현.

### 숙박·이동 폼 (`StayLegEditors.tsx`)
형식만 B1에 맞춘다(칸 순서·시간대 자동·하단 고정 버튼). 로직 변경 없음.

## 3. 시험·검증

- 기존 E2E의 `setLocalTime`/`setDateOnly` 류 헬퍼를 새 폼에 맞게 고친다. 단언은 유지. 고급 접기 안 값으로 기존 시험 데이터(`text`/`instant`)가 그대로 입력되는지 확인.
- 새 검사: (a) 방문 기록 한 번 누르면 `local` 정밀도·여행 시간대·현재 시각으로 저장되고 정정 가능 (b) 종료 시각 다음 날 저장과 표시 (c) 변경 이유 입력이 `ChangePlan.reason`에 반영되고 회고에 보임 (d) 시간대 `unknown` 여행에서는 시간대 칸이 보임 (e) 모바일에서 긴 폼의 저장 버튼이 스크롤 없이 보임.
- C-06·C-07 통합 시험 통과(데이터 의미 불변). 최종 `pnpm run check:deferred`.
