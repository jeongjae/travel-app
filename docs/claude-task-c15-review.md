## 2. 수정 지시 R1 (Claude, 같은 브랜치)

- **R1-a 한국어 역 이름 판정.** `day-photos.ts`의 `TRANSIT_NAME`에 있는 `역\b`는 한국어 이름과 일치하지 않는다(JS `\b`는 영문·숫자 경계만 본다). 독립 확인: `삿포로역`·`오타루역 앞`·`JR 삿포로역 남쪽 출구` 모두 `false`. 파리 패키지는 프랑스어 이름이라 영향 없지만 삿포로 등 한국어 장소 이름 여행에서 역 사진이 대표가 될 수 있다.
  - `역`이 낱말 끝일 때 일치하도록 고친다(예: `역(?![가-힣])`). `역사`·`역삼` 같은 낱말 안의 `역`은 이동으로 보지 않는다.
  - 단위 시험: 위 3건 `transit`, `역사 박물관` `sight`.
- **R1-b 목차 이동 대상의 안정성.** 머리말 id를 렌더 중 바뀌는 지역 변수(`headingCount`)로 매기고, 목차는 `extractHeadings`의 정규식으로 따로 센다. 두 방식이 다르게 세면(인용·목록 안의 `##`, 밑줄식 머리말, 개발 모드 `StrictMode` 이중 렌더) 목차 단추가 다른 머리말로 가거나 아무 데도 가지 않는다. 지금 시험은 가상 3개 머리말과 실제 Aix 목차 **개수**만 본다.
  - id를 렌더 횟수와 무관하게 정한다(예: 렌더된 머리말 텍스트·순서를 같은 마크다운 해석에서 얻거나 rehype 단계에서 id 부여). 방식은 Claude가 정하고 이유를 결과에 적는다.
  - 실제 패키지 시험: **지역 가이드 9개 전부**에서 목차 단추마다 대상 요소가 있고 그 글자가 단추 글자와 같은지 단언. 개발 서버(5173, StrictMode)에서도 한 가이드 수동 확인.
- **R1-c 스크린샷 다시 찍기.** `UI_C15_SHOTS=1`로 `docs/design/ui-c15/` 6장 갱신. 대표 사진·`사진 N장` 띠가 보이도록 날짜 화면 사진은 대표 사진 위치까지 내려 찍는다.
- 시험: `pnpm run check`, 바뀐 spec. 전체 E2E는 GitHub CI 결과로 갈음해도 된다(PC 메모리 부족 재발 방지).
