# T-D1 결과 · AI 전송 최소화·동의·의미 검증

2026-11-06 · 기준 main `c678390` · 브랜치 `codex/d01-send-semantics` · **Claude 자체 검사 완료 / Codex 검토 대기 / 사용자 미확인**

## 요약

1. **G1~G8, G10, G15, G18을 구현했다.** 실행 환경은 로컬 Node 서버와 모의 provider이고, OpenAI 실제 호출과 키 사용은 없다.
2. **전송:** 조사 호출에 요청 원문이 가지 않는다. 작성 호출은 허용 목록이고 표식 전수 시험으로 허용 밖 값 0을 단언한다.
3. **동의:** 빌더의 `consent: true`를 없앴다. 내용·서버·모델·한도 지문에 묶이고, 지문이 다르면 서버가 400으로 거부한다.
4. **검증:** 도착 전·출발 후·고정 활동과 겹침·종료<시작을 거부한다. 03시는 경고만 한다.
5. **카드:** 항목별 사유, 출처 종류·개수, 확인 시각, 예약·이동 영향을 보여 준다. 변하는 사실은 공식 출처와 확인 날짜가 없으면 미확인이다.
6. **확인 필요:** 예약 활동의 시각 변경·제거는 따로 표시하지 않으면 일괄 적용에서 빠진다.
7. **응답:** 거절·길이 초과·미완성과 예산 차단·속도 제한을 구분하고 `usage`를 작업에 기록한다.
8. **간헐 실패:** 시험 폴더를 OS 임시 폴더로 옮겨 단독 20회 실패가 7회에서 0회로 줄었다. 앱의 EPERM(G9)은 그대로이며 T-D2 몫이다.
9. **구조 변경:** 서버가 전체 활동을 모르게 되어 변경안 완성이 브라우저로 옮겨졌다(§2).
10. **저장 스키마·저장 명령 변경 없음.** 단, 그 제약 때문에 절충한 곳이 3개 있다(§3).

**검사:** `pnpm run check` exit 0(363 통과·1 건너뜀). AI E2E 10개 통과. 통합·회고 E2E는 카드 표시 수정 전에 통과했다. 전체 E2E는 CI로 갈음한다.

**Codex가 먼저 볼 곳:** §3 절충 3건, §5 미검증.

## 2. 계약·구조 변경

`src/ai-v2-contract.ts` 변경 목록:

- 요청: `context`와 `consent: true`를 없애고 `scope`·`research`·`planning`·`consent{server, model, limits, fingerprint}`로 나눴다. `scope`는 OpenAI로 가지 않는다.
- 출력: 항목에 `reason`, 근거에 `checkedAt`·`operationIndexes`를 더했다. 근거 최대 20건을 19건으로 줄였다(사유 행 1건 몫).
- 작업 결과: 완성된 변경안 대신 `{output, sources, planning, warnings}`. 작업에 `usage`를 더했다.

**변경안 완성이 브라우저로 옮겨졌다.** 서버가 받지 않은 필드(`officialUrl`, `taskRefs` 등)를 보존하려면 전체 활동을 아는 쪽에서 완성해야 한다. `materializeV2Proposal`을 `src/ai-v2-semantics.ts`로 옮겼고, 서버와 브라우저가 같은 `validateAiV2Output`을 쓴다. 재회수가 중복 저장되지 않도록 현재 시각 대신 작업 완료 시각을 쓴다.

**시험 변경(약화 여부 검토 요청):**

- "여행·계획 불일치" 시험은 요청 안의 중복 `tripId`가 사라져, 없는 날짜 참조와 여행 범위 밖 날짜 시험으로 바꿨다.
- 기록 전체 전송 단언은 지침에 따라 고른 기록만 전송으로 바꿨다.
- E2E 모의 라우트의 `records = []` 단언은 기록 선택 시험과 공존하도록 개별 시험으로 옮겼다.

## 4. 지침과 다르게 해석한 곳

- **도착·출발:** 지침은 "leg 시각에서 얻는다"고 했지만 이동에는 시각 필드가 없다. 그날 첫·마지막 이동이 장거리(항공·철도·페리 등)일 때 그 도착·출발 활동의 시작 시각으로 얻고, 아니면 요청 화면 입력을 쓴다. 도보 이동까지 쓰면 정상 일정을 거부하게 된다.
- **고정 활동:** `bookingIds`가 있는 활동만 고정으로 본다. 시각이 없는 예약 활동은 겹침 검사 대상이 아니다.
- **변하는 사실 판정:** 낱말 목록으로 찾으므로 놓치거나 과하게 잡을 수 있다.
- **확인 시각:** 공식 출처가 밝힌 날짜만 "확인"으로 표시하고, 나머지는 "수집 … (확인 시각 없음)"으로 표시한다.

## 5. 미검증

- 실제 OpenAI 응답과 새 출력 스키마의 호환(strict 구조화 출력 포함). 실제 호출이 없다.
- E2E는 서버를 `page.route`로 모의한다. 로컬 Node 서버의 HTTP 경로는 단위 시험으로만 지난다. 지문은 양쪽이 같은 함수를 쓴다.
- 실제 여행 데이터에서 허용 필드에 무엇이 들어 있는지와 요청 크기.
- iPhone 실기기. 전체 E2E는 CI 결과로 확인한다.
- T-D1 이전 `jobs.json`의 완료 작업은 새 형식이 아니어서 자동 저장을 건너뛴다(로컬 개발 자료만 해당). 해당 작업은 다시 요청해야 한다.
