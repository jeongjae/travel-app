## 발견·수정한 문제

1. 8787은 바인딩 검사에서 EADDRINUSE였다. 소유 불명 프로세스를 종료하지 않고 브라우저 검증 서버를 UI 전용 4173으로 분리했다. 실제 AI 호출은 모의 응답으로 대체했다.
2. 첫 새 E2E는 계획 선택 시 목록으로 돌아가는 동작을 고려하지 않았고 비동기 저장 완료 전에 재로드했다. 상세를 다시 선택하고 저장 완료/활성 초안 버튼을 기다리도록 검사 가정을 수정했다.
3. 기존 화면의 실제 기록은 선택 필드를 undefined로 저장할 수 있었다. 새 JSON 지문 규칙으로 직접 검사하면 검토가 차단됐다. v1 전용 tagged canonical 지문으로 누락/undefined/배열/객체를 구분해 원문 비교하고, v2 JSON 규칙은 유지했다. 실제 전환 E2E PC/모바일 재통과.
4. v1 미확인 조사 근거의 수집 시각을 확인일로 승격하지 않도록 수정했다. 이전 결정에 사용자/시각이 누락된 경우 값을 발명하는 대신 원문을 보존하며 변환을 거부한다.
