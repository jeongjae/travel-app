# T-D5 iPhone 실기기 대본·기록표 (U1~U6)

지시: [C2 §2](claude-task-d05-c2-iphone.md) · 결과: [claude-task-d05-result.md](claude-task-d05-result.md) · 앱: `https://jeongjae.github.io/travel-app/`

- 수행: **사용자**(iPhone Chrome). Claude는 사용자가 불러 준 값만 받아 적는다. 가상 인증기·에뮬레이션 결과는 여기에 옮기지 않는다.
- 적는 값: 날짜·시각·건수·크기·통과/실패·화면 문구·"오류 상세" 코드. 여행 본문·장소명·사진·예약 정보·토큰은 적지 않는다.
- 사용자 확인 상태: **확인 대기**

## 준비물

- iPhone: Chrome(PC와 같은 Google 계정), Wi‑Fi, 블루투스 켬, Face ID 사용 가능
- PC: Chrome, 블루투스 켬(QR 재추가가 필요할 때만)
- 결과 칸: `통과` / `실패` / `건너뜀`

## 멈춤 조건 (그 자리에서 멈추고 Claude에게 화면 문구를 그대로 알린다)

- iPhone Chrome에서 "패스키로 로그인"이 실패한다 (G-P)
- 백업 저장이나 복원이 실패한다 (G-B)
- "오류 상세"에 `HTTP 500`이 보이거나, 화면이 비거나, 앱이 멈춘다
- 평소 여행의 일정이 뜻하지 않게 바뀌어 보인다
