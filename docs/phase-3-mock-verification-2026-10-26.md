2026-10-26 · **로컬 모의·경계 검증 통과 / 실제 API·G3 사용자 확인 미완료**

## 범위와 보호

- 시작 HEAD=`07ce016`, main. 기존 미추적 `docs/status-review-2026-10-26.md`는 보존·커밋 제외. 시작 시 5173·4173·8787 리스너 없음. 기존 사용자 DB·검토 프로필을 열거나 초기화하지 않았다.
- 프로젝트 pnpm12.14.0·Node24.13.1·`.cache/corepack`·`.cache/ms-playwright`를 사용한다. 작업 파일은 가상 fixture와 `.cache/ai-v2-tests/`만 사용했다.
- 실제 키를 읽거나 바꾸지 않았고 `.env.local`을 로드하지 않았다. `OPENAI_V2_ENABLED`·호스팅·인증·모델/예산·전송 범위도 변경하지 않았다. 실제 OpenAI 호출·유료 실행·AI 서버 공개는 없다.
- HTTP 검사는 localhost의 임시 서버에 가짜 provider를 주입한다. E2E의 유료 실행 동의 체크는 가짜 API 응답에만 연결되며 실제 동의/과금 증거가 아니다. 외부 요청0건을 확인한다.

## 발견·수정한 오류

`materializeV2Proposal`에서 AI가 `add`에 기존 `activityId`를 넣으면 기존 활동의 예약/작업 참조까지 새 활동으로 복사될 수 있었다. 지시문에는 새 활동의 ID를 비우도록 했지만 로컬 검사는 없었다. 기존 ID로 추가를 요청하는 가상 회귀가 수정 전 실패하는 것을 확인했다.

`server/ai-v2.ts`에서 이런 출력을 거부한다. 정상적인 빈 ID 추가는 새 활동 ID와 빈 예약/작업 참조로 만든다. 기존 편집·삭제 경로는 유지한다. 확인 후 적용·revision 검사는 저장소의 기존 트랜잭션을 사용한다.

모의 UI 화면에서 체크박스가 일반 입력창의 폭/높이를 상속해 설명과 떨어져 있는 문제도 확인했다. 체크박스는20px로 표시하고 label을 같은 행의44px 터치 영역으로 보완했다. 앱/가상 표본만 공개했으며 실제 AI 서버를 배포하지 않았다.
