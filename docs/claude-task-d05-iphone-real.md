## 1. C1 코드 준비 (실제 호출 없음)

### A. 두 번째 패스키 (iPhone)
현재는 자격 0개일 때만 등록되고 PC의 Windows Hello 패스키는 iPhone에서 쓸 수 없다.
- **로그인된 상태에서만** 패스키를 추가한다: `POST /auth/credentials/options`·`POST /auth/credentials`(Bearer 필수, 등록 코드 불필요). 자격 최대 3개. 목록(`GET /auth/credentials`: 등록 시각·마지막 사용 시각·라벨만)과 삭제(자기 자신 외 1개 이상 남을 때만).
- 화면: AI 패널 "패스키 관리" — 추가 시 브라우저의 **"다른 기기(휴대폰)"** QR 경로로 iPhone에 패스키를 만든다(PC에서 로그인 → 추가 → QR → iPhone Face ID). 라벨 입력.
- 시험: 무인증 추가 401 · 4번째 추가 거부 · 마지막 1개 삭제 거부 · 추가한 자격으로 로그인. 가상 인증기 2개 E2E.

### B. 인증된 작업 목록 (CL-38)
- `GET /api/ai/v2/jobs?tripId=`(Bearer 필수) — `toStoredJob` 필드만, 최근 50건. 화면 변경안 탭에 "AI 작업 기록"(상태·시각·토큰·웹 검색 수, 내용 없음). canary 시험에 목록 응답 포함.

### C. officialUrl 입력 (CL-26)
- 일정 수정 폼에 "공식 사이트 주소(선택)" 입력 → 기존 저장 명령으로 `officialUrl` 저장. 저장 스키마에 이미 있는 필드만 쓴다. **데이터 경계 4경로를 건드려야 하면 멈추고 보고.**

### D. 관측 보강
- 한도 초과 응답의 HTTP 코드·오류 코드를 화면 오류 상세(접힘)에 표시(429 직접 관측용).
- 작업별 웹 검색 수와 OpenAI 응답의 도구 호출 항목 수를 함께 기록(CL-37 대조용, 내용 없음).

완료 조건: check·E2E·CI 성공, 데이터 경계 0건(§C 예외 시 멈춤), push → Codex 검토 → 병합 → Claude가 `wrangler deploy --env production`.

## 2. iPhone 실기기 (가상·기존 데이터, 실제 호출 없음)
사용자 수행, Claude는 대본 `docs/d05-iphone-script.md`와 기록표 준비.
1. 배포 앱 열기 → 홈 화면 추가 → 기존 저장소 유지 확인(10/27 가져온 데이터).
2. G-P: PC에서 패스키 추가(QR) → iPhone에서 **패스키로 로그인** → "패스키 로그인됨".
3. 화면 점검: 오늘·일정·기록·회고·변경안·AI 패널(세로, 한 손), 글자 잘림·가로 스크롤 없음.
4. 비행기 모드: 일정 조회, 방문 기록 1건, 예정 외 기록 1건, 저장된 변경안 조회. AI 전송 단추 비활성·"오프라인" 표시.
5. 브라우저 종료·재실행 뒤 기록 유지. 토큰 만료(1시간) 뒤 재로그인.
6. G-B: 전체 백업 → 파일 앱 저장(크기 기록) → 빈 검토 공간(`?review=d05-restore`)에 복원 → 일정·사진·기록 조회.

## 3. 실제 여행 선별 호출 (G-T·G-P·G-B 뒤)
1. **1단계 — PC, 실제 패키지의 사본**: 검토 공간 `?workspace=content&review=d05-real`에 실제 패키지를 가져와 G-T 범위로 요청 2회(추가 1 → 거절, 수정 1 → 적용). 평소 공간의 계획은 바뀌지 않는다. 전송 미리보기를 사용자가 읽고 동의 단추를 직접 누른다.
2. **2단계 — iPhone, 평소 공간**(G-T ④가 "적용까지"일 때만): 요청 1~2회. 적용 전 계획 버전이 보존되는지, 적용 뒤 "계획 버전"에서 되돌아볼 수 있는지 확인.
3. 매 호출: 전송 미리보기의 항목 수(날짜·활동·장소·기록), 토큰, 웹 검색 수, 추정·대시보드 금액, 검증 거부·재작성 횟수, 출처 종류 분포, "변하는 사실" 표시를 기록. CL-29(오후 출발일·이동일 거부) 해당 날이 범위에 있으면 결과 기록.
4. 끝나면 `d05-real` 검토 공간 삭제, 사용량 합계, ACK 확인.
멈춤: 1회 $0.3 초과 · 미리보기에 "보내지 않는 항목"(예약 번호·메모·숙소 상세·사진 등)이 보임 · 검증 거부 연속 2회 · 평소 공간 계획이 동의 없이 바뀜.
