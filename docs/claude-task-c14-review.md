## 2. 수정 지시 R1 (Claude, 같은 브랜치)

- **P7 첫 화면 입구 하나로.** `p7-start-mobile.png`에 pilot.zip 파일 입력이 **두 개**(위쪽 접기 `원천 패키지 가져오기 (pilot.zip)`, 본문 `여행 패키지(pilot.zip) 가져오기`)가 동시에 보인다. CL-22(어느 것을 눌러야 하나)의 원인이 그대로 남고 오히려 늘었다. 지시서 P7 문구("위쪽 접기 입구와 같은 동작")가 중복을 허용하는 것으로 읽힐 여지가 있었다(Codex 지시 표현 문제).
  - 여행이 **하나도 없을 때**: 위쪽 패널에는 `새 여행`·`가상 여행 둘러보기`만 두고 파일 입력은 숨긴다. 본문의 가져오기 하나만 남긴다.
  - 여행이 **있을 때**: 지금처럼 위쪽 여행 메뉴의 `원천 패키지 가져오기`만.
  - 본문 백업 안내는 문장 중간 단추 대신 `전체 백업에서 되살리기: 저장소·백업` 한 줄(단추는 줄 끝)로, 390px에서 줄바꿈이 문장을 끊지 않게.
- 시험: `ui-c14.spec.ts`에 "여행 없음 → 파일 입력 1개", "여행 있음 → 첫 화면 본문 입력 없음" 단언. 전체 E2E 1회.

## 3. 남은 후보 (차단 아님)

- 기록 메모의 원천 키(`stay:Nice · …`)는 저장 본문이라 범위 밖(Claude 보고). 원천 키 표시 정리는 이행 어댑터 다음 버전 후보.
