## 1. 바뀐 라벨 대응표
| 이전 | 이후 |
|---|---|
| `여행 패키지 선택` | `원천 패키지 가져오기 (pilot.zip)` |
| `전체 백업 파일 선택` | `전체 백업 복원 (travel-app-backup-*.zip)` |
| `첨부 복구용 패키지·백업 선택` | `첨부 사진만 복구 (여행·계획은 바뀌지 않음)` |

E2E 선택자는 `getByLabel` 부분 일치로 `원천 패키지 가져오기`·`전체 백업 복원`·`첨부 사진만 복구`로 바꿨고 단언은 그대로다(14개 파일).

## 2. 동작 변경
- **A1·A2** `Recovery.tsx`: 여행이 있으면 복원 입력 위에 "이 공간에 여행 N개가 있어 전체 복원을 할 수 없습니다. 전체 복원은 빈 공간에서만 합니다. → `새 빈 공간 열기`"와 버튼. 버튼은 `restore-YYYYMMDD-N`(N은 브라우저 저장소 카운터, 못 쓰면 무작위)로 새 탭을 열고 현재 공간은 그대로 둔다.
- **A3** 복원 완료 문구: "전체 복원 완료. 복원한 여행은 이 공간(restore-…)에 있습니다. 여행 메뉴에서 전환해 쓰세요."
- **B** 잘못된 파일 안내(오류는 해당 입력 바로 아래 `role="alert"`; 저장소 대화상자는 입력별로 위치 구분, 원천 패키지 입력은 기존 `main` 오류 영역).

| 입력 | 이전 | 이후 |
|---|---|---|
| 원천 패키지 입력에 백업 ZIP | 현재 입력은 이행 패키지 v2입니다. 백업/복사형 가져오기는 별도 경로입니다. | 전체 백업 파일입니다. `더보기 → 저장소·백업 → 전체 백업 복원`에서 빈 공간에 복원하세요. |
| 백업 복원 입력에 원천 패키지 | 백업 검증: 전체 백업 v2 필요 | 원천 패키지입니다. 여행 메뉴의 `원천 패키지 가져오기`를 쓰세요. |
| 알 수 없는 ZIP | (위 첫 문구) | 알 수 없는 파일 형식입니다. |
- **C** `docs/c07-sapporo-scenario.md`·`c07-user-check.md`: 메뉴 이름을 U1 기준으로 갱신(`일정`·`기록`·`더보기 → 저장소·백업`), S6 복원은 `새 빈 공간 열기` 사용, 비활성 한 줄과 확인 항목 S6-d 추가.
- **D** `기록` 탭의 `날짜별 회고 보기`를 기본(채움) 버튼으로. 종료일이 지난 여행의 `오늘` 탭 위에 "여행이 끝났습니다. 회고 보기" 링크. 회고 화면 본문은 미변경.

## 5. 미검증·한계
- 사용자 백업 파일(개인 입력)로의 실제 복원은 이번에 실행하지 않음(가상 백업만). 사용자 확인 상태: **검토 준비**.
- `새 빈 공간 열기`의 번호 카운터는 브라우저 저장소 기준이라 다른 브라우저/프로필에서는 같은 이름이 나올 수 있다(이미 쓴 이름이면 그 공간이 열림).
- 원천 패키지 입력의 오류는 `main` 상단에 표시되어 여행 이름 메뉴가 길면 입력과 떨어져 보일 수 있다.
