## 2. 고칠 것

### Q1 여행 이름·메모
1. 여행 이름이 보이는 **모든** 곳(대화상자 제목, 회고·백업·미리보기 문구, 알림)에 `tripDisplayName`. 파일 이름 등 저장·내보내기 값은 제외. `rg "header.name|trip.name|\.name}"` 등으로 전수 확인하고 목록을 결과에 남긴다.
2. 메모 목록의 `원천 대상 stay:Nice · 앱 예약 연결 미확정`: 저장 본문인지 구조 필드에서 만든 문구인지 확인. 구조 필드면 `숙소 Nice · 예약 연결 전`처럼 사람 말로. 본문이면 손대지 않고 결과에 기록.

### Q2 준비·회화와 가이드 상세
1. **준비·회화 묶음**: `여행 전체`(이용법·하이라이트·전체 일정·예약·긴급 연락처·회화) 절을 맨 위, 그 아래 **여행 순서대로** 지역 절(Barcelona → Girona·Empordà → Nice·Côte d'Azur → Verdon → Aix → Luberon → Avignon → Lyon → Paris, 실제 순서는 일정의 첫 등장일 기준). 각 절에 지역 머리말을 두고, 절 안의 단추에서는 지역 접두를 뺀다. 절 안 순서 고정: 지역 가이드 → 생활·도착·귀가 → 교통권 → 그 밖. 묶음 이름은 지역의 표시 이름 하나로 통일(`Aix`/`Aix-en-Provence` 혼용 금지).
2. `Commercial Guide Module`: 본문을 읽고 한국어 표시 이름을 정한다(예: 상점·영업 안내). 저장 제목은 그대로, 표시만.
3. **가이드 상세 화면**: 위에서부터 ① 제목(표시 규칙 적용) ② 이 가이드의 **목차**(본문 `##`/`###` 머리말, 눌러 이동) ③ 본문. `가이드 제목 수정`·`지역 본문 편집` 등 편집 단추는 머리 오른쪽 `⋯ 편집` 메뉴 하나로. `원천 지역 속성`(slug·원천 경로)은 맨 아래 `원천 정보` 접기로. `지역 본문 / 원천 지역 속성` 전환 단추는 없앤다. 맨 위·맨 아래에 `준비·회화로` 돌아가기.
4. 지역 화면·장소 화면도 같은 규칙(읽기 먼저, 편집은 메뉴, 원천 정보 접기)인지 확인하고 같으면 함께.

### Q3 날짜 사진
1. **대표 사진 고르기(표시 규칙)**: 그날 `assetRefs` 중에서 ① 그날 `highlights`·제목·`cityText`에 이름이 나오는 장소 ② 이동(역·공항·렌터카)·식사(빵집·카페·식당)·숙소가 아닌 장소 ③ 원래 순서. 장소 종류는 `placeKind`·`grade`·연결 활동 제목·장소 이름을 근거로 판정하고, 판정 규칙은 단위 시험으로 고정한다. 저장된 `assetRefs` 순서는 바꾸지 않는다.
2. **사진을 활동에 붙인다**: 하루 일정의 각 활동 카드에 그 활동의 방문 장소 사진이 있으면 작은 썸네일(모바일 56px)과 캡션 장소 이름. 날짜 요약에는 대표 사진 1장 + `사진 N장` 띠(가로 스크롤)로 그날 사진을 모두 보이게. 사진이 어느 활동 것인지 화면에서 알 수 있어야 한다.
3. **43일 대조표**: 실제 패키지로 날짜별 `이전 대표 → 새 대표 · 고른 이유` 표를 결과 문서에 남긴다(장소 이름만, 사진·본문은 커밋 금지). 사진이 없는 날(9/29 도착일·10/10 귀국일 등)은 `사진 없음`으로 보이는지.
4. 표시 규칙으로 어색한 날이 남으면 그 날짜와 원인을 표에 적는다(어댑터가 출발역을 `visit`로 연결한 문제 등은 어댑터 v5 후보로만 기록).
