# Claude Sonnet C-11〔REG-03〕· 백업 복원 경로와 회고 진입 안내

2026-11-03 · 기준 `codex/c09-day-photo` `1581908` 이후(C-09 검토 뒤 분기) · **전달 준비 / 구현 미착수 / U2보다 먼저**

> 사용자 보고(11/03, 삿포로 대본 수행 중): 전체 백업을 복원하지 못했고 회고 메뉴를 찾지 못했다.
> Codex 조사: **데이터 손실 없음.** 백업 파일은 온전하며 빈 공간에 복원하면 여행·기록·회고가 그대로 열린다(아래 증거).
> 원인은 복원 조건과 ZIP 입력 3종의 차이를 화면이 설명하지 않는 것이다. 이를 고치고, 대본을 새 메뉴 이름으로 갱신한다.

## 1. 조사 증거 (Codex, 2026-11-03)

| 항목 | 확인 |

| 백업 파일 | `backup/travel-app-backup-7e584f80-….zip`(07:18) · `travel-app-backup` v2 · 여행 1(삿포로 연말 가상여행, Asia/Tokyo) · 계획 버전 15 · 활동 90 · 숙박 5 · 이동 7 · 기록 9 · cutSeq 33. 07:13 파일도 같은 내용 |
| 복원 재현 | 클라우드에서 `1581908` 빌드 후 새 빈 검토 공간에 이 파일을 복원: 미리보기 1개 여행 → 복원 완료 → 재실행 후 제목·오늘 화면·`기록 → 날짜별 회고 보기`에 공항 도착·카운트다운 산책 기록 표시 |

## 2. 범위

### A. 복원 조건을 화면에서 설명한다 (`Recovery.tsx`)
1. 여행이 있는 공간에서는 `전체 백업 파일 선택`을 비활성으로 두되 **바로 위에 이유와 해법**을 쓴다:
   "이 공간에 여행 N개가 있어 전체 복원을 할 수 없습니다. 전체 복원은 빈 공간에서만 합니다. → `새 빈 공간 열기`"
2. `새 빈 공간 열기` 버튼: `review=` 이름을 자동 생성(`restore-YYYYMMDD-N`)해 **새 탭**으로 연다. 현재 공간은 그대로 둔다. 평소 공간(review 없음)에서 눌러도 검토 공간을 연다(평소 공간은 덮어쓰지 않음).
3. 복원 완료 뒤 안내: "복원한 여행은 이 공간(`restore-…`)에 있습니다. 여행 메뉴에서 전환해 쓰세요."
4. 세 ZIP 입력의 이름을 역할이 보이게 바꾼다:
   - `여행 패키지 선택` → `원천 패키지 가져오기 (pilot.zip)`
   - `전체 백업 파일 선택` → `전체 백업 복원 (travel-app-backup-*.zip)`
   - `첨부 복구용 패키지·백업 선택` → `첨부 사진만 복구 (여행·계획은 바뀌지 않음)`
   화면낭독기 이름(`getByLabel`)이 바뀌므로 E2E 선택자를 함께 고친다(단언 유지).

### B. 잘못 넣은 파일을 알아본다 (`package.ts`, `ContentApp.tsx`)
1. `readPackage`가 `manifest.format === 'travel-app-backup'`이면 오류 문구를 **"전체 백업 파일입니다. `더보기 → 저장소·백업 → 전체 백업 복원`에서 빈 공간에 복원하세요."**로. 반대로 `readBackup`에 원천 패키지를 넣으면 "원천 패키지입니다. 여행 메뉴의 `원천 패키지 가져오기`를 쓰세요."
2. 기존 문구 "현재 입력은 이행 패키지 v2입니다…"는 다른 형식(알 수 없는 ZIP)일 때만 남기고 "알 수 없는 파일 형식입니다"로 바꾼다.
3. 오류는 입력 바로 아래 `role="alert"`로 보인다(토스트만으로 끝내지 않음).

### C. 대본·기록 양식 갱신 (U4 일부를 앞당김)
`docs/c07-sapporo-scenario.md`·`c07-user-check.md`의 메뉴 이름을 U1·이번 변경 기준으로 고친다(`전체 일정`→`일정`, `더 보기 → 실제 기록`→`기록`, `저장소·백업`→`더보기 → 저장소·백업`, S6 복원은 "새 빈 공간 열기" 버튼 사용). 대본 S6에 "같은 공간이나 다른 여행이 있는 공간에서는 복원이 비활성"을 한 줄 넣는다.

### D. 회고 진입(소규모)
`기록` 탭 상단의 `날짜별 회고 보기`를 기본(채움) 버튼으로 올리고, 여행 종료일이 지난 여행에서는 `오늘` 탭 머리에도 `회고 보기` 링크를 둔다. 회고 화면 본문은 U3 범위라 손대지 않는다.

## 3. 시험
- 새 E2E: (a) 여행이 있는 공간에서 비활성 이유·`새 빈 공간 열기`가 보이고 새 탭의 빈 공간에서 복원이 된다 (b) 백업 ZIP을 원천 패키지 입력에 넣으면 안내 문구, 그 반대도 (c) 첨부 복구 입력은 여행 수를 바꾸지 않는다.
- 기존 복원 E2E는 라벨만 바꾸고 단언 유지. C-06·C-07 통합 시험 통과. 최종 `pnpm run check:deferred`.
- 사용자 백업 파일은 fixture로 커밋하지 않는다(개인 입력). 가상 백업으로 시험한다.
