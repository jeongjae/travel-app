## T-E3-2 — 기존 장소 내용을 글로 고치기 (main 병합 11/26)

시험 여행으로, PC·iPhone.

| # | 볼 곳 | 기대하는 모습 |
|---|---|---|
| 1 | "AI로 수정하기"로 복사 → `## 장소` 표에서 기존 장소의 설명을 바꿔 붙여넣기 | "기존 장소 수정 1건"이 나오고 체크는 꺼져 있다. 바뀌는 칸의 전·후가 보인다 |
| 2 | 체크하고 승인 | 장소 화면에 새 설명이 보인다. 같은 글의 일정 변경도 이어서 적용된다 |
| 3 | 이름 칸만 바꿔 붙여넣기 | 이름은 바뀌지 않고 "이름은 글로 고치지 않습니다" 안내 |
| 4 | 저장소·백업 → 전체 백업 복원에서 백업이 아닌 파일 고르기 | 한글 안내(전에는 영문 `File format is not recognized`) |

참고(Codex가 수용한 것): 지역이 여러 개 연결된 장소는 지역 칸을 고치면 연결이 하나로 바뀐다.

## T-P2-1 — 준비 자료 파일 (main 병합 11/26)

"AI로 계획 만들기"의 가이드 구역. PC에서 저장 → iPhone에서 불러오기를 한 번 해 보면 좋다(iPhone 동작은 **미확인**).

| # | 볼 곳 | 기대하는 모습 |
|---|---|---|
| 1 | 가이드를 넣고 몇 개 고른 뒤 **준비 자료 저장**/**준비 자료 복사** | 파일 `준비자료-<목적지>.md`. 옆에 "예산·동행 포함" 안내 |
| 2 | 그 글을 가이드 칸에 넣기(붙여넣기·파일 선택) | 미리보기: 항목 수, 고른 것 건수, 취향 답 칸 수, 체크 2개 |
| 3 | 반영 | 같은 항목이 같은 상태로 골라져 있다. "취향 답도 가져오기"를 켰을 때만 취향 답이 바뀐다 |
| 4 | 가이드가 이미 있을 때 반영 | "지금의 가이드와 고른 것 n건을 바꿉니다" 확인. 취소하면 그대로 |
| 5 | 계획 붙여넣기 화면에 준비 자료를 넣기 | 가이드 칸에 넣으라는 안내 |

Codex가 정한 세부(사용자 합의 아님 — 맞지 않으면 말해 달라): 취향 답 8칸만 담음, "고른 것도 가져오기" 기본 켬·"취향 답도 가져오기" 기본 끔, 파일에서 비어 있던 칸은 지금 값을 남김.
