## 결정과 이번 범위

사용자 확정은 ‘가능한 SP-FR-guidebook의 UI/UX 경험을 살리는 방향’이다. DB화와 여러 여행 재사용을 유지하면서 원본의 탐색·읽기 흐름을 기준으로 삼는다. 세부 구현 판단은 작성자의 판단으로 구분한다. 이번 대상은 기존 실제 3일 검증 표본이며 전체 이행으로 확대하지 않는다.

## 대조 기준과 구현 판단

- 원본 기준: 고정 commit `35498adc6413dad45922f2dab87781afeb04d898`의 `build/shell.py`, `build/assets/style.css`, `build/render.py`. 배포 HTML/CSS는 읽기 전용으로 별도 대조했다.
- 원본 사이트 직접 접속은 실행 환경의 DNS 제한으로 실패했다. GitHub 연결에서 배포 HTML/CSS를 읽어 로컬에서 정적 화면을 렌더링했다. 원본의 동적 JavaScript·외부 지도 동작을 실검증한 증거로 사용하지 않는다. 원본 본문·화면 파일은 `local-data/`에만 보관한다.
- 원본의 오늘·전체 일정·가이드·지도·준비를 기본 탐색 축으로 삼고, 날짜를 우선 표시한다. 표본 내부 순번을 원본 Day 28~30으로 추정해 표시하지 않는다.
- 하루는 첫/다음 일정·오늘 예약·시간표를 먼저 읽고 장소 안내로 이동한 뒤 같은 날짜로 돌아오게 한다. 이동 구간은 출발 활동 옆에 표시한다.
- 따뜻한 바탕 `#FAF6EF`, 남색 상단 `#000091`, 주색 `#0F5878`, 본문 17px/행간 1.7/읽기 폭 672px를 원본에서 대응한다. 가이드 목차·이미지 카드·지역 우선 탐색을 반영한다.
- 여행 선택·가져오기, 예약/기록/변경안, 계획 버전·이행 점검은 보조 도구로 둔다. 저장소·백업은 상단에서 항상 접근한다. 기존 DB·OPFS·저장 트랜잭션은 변경하지 않는다.

## 검증과 확인 상태

현재 구현·회귀 보정 중이다. 형식/린트/119개 단위·빌드 검사를 통과한 시점이 있으나 후속 변경의 최종 결과는 종료 시 갱신한다. 새 탐색 흐름은 PC에서 통과했고 기존 검사에서 접힌 메뉴·접근성 이름에 따른 경로를 수정 중이다. 실제 표본의 전체 행/47파일·오프라인 편집·복원도 새 사본으로 재검증한다.

검증 경로는 `http://127.0.0.1:4173/?workspace=content&review=phase-1`이며 기존 사용자 전용 프로필을 보존한다. 원본과 완전히 같은 픽셀·동작을 재현했다고 판정하지 않는다. 원본의 내부 지도 조작·회화 부가기능, iPhone Chrome 실기기, 표본 밖 전체 여행은 별도 검증/후속 범위다.

G1은 사용자에게 보정된 실제 화면을 다시 제시한 뒤 판정한다. 이번 개발 진행·GitHub 반영 요청을 G1 확인 완료로 기록하지 않는다.

## GitHub 작업 단위

1. 사용자 결정·요구사항·실행계획과 협업 규칙 반영.
2. UI/UX 보정 코드·회귀 검사·최종 검증 결과 반영.

실제 원문·예약·ZIP·이미지·브라우저 프로필은 커밋에서 제외한다. 커밋과 push 완료 결과는 각 작업 종료 때 기록한다.
