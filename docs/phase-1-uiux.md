사용자 확정은 ‘가능한 SP-FR-guidebook의 UI/UX 경험을 살리는 방향’이다. DB화와 여러 여행 재사용을 유지하면서 원본의 탐색·읽기 흐름을 기준으로 삼는다. 세부 구현 판단은 작성자의 판단으로 구분한다. 이번 대상은 기존 실제 3일 검증 표본이며 전체 이행으로 확대하지 않는다.

검증 경로는 `http://127.0.0.1:4173/?workspace=content&review=phase-1`이며 기존 사용자 전용 프로필을 보존한다. 원본과 완전히 같은 픽셀·동작을 재현했다고 판정하지 않는다. 원본의 내부 지도 조작·회화 부가기능, iPhone Chrome 실기기, 표본 밖 전체 여행은 별도 검증/후속 범위다.

기존 `user-review-final/browser-profile`을 그대로 사용해 실제 Chromium 창을 다시 열었다. 새 빈 탭에서 앱 버전만 갱신했으며 ZIP 재가져오기/데이터 초기화는 하지 않았다. `user-review-final/uiux-ready.json`과 화면에서 5개 메뉴를 확인했다. 이후 사용자의 명시적 ‘확인 완료’ 응답으로 G1을 닫았다. 개발 진행·GitHub 반영 요청 자체를 확인으로 대신하지 않았다. 전체 여행·실기기 확인과는 구분한다.
