## 자동 회귀

`COREPACK_HOME=.cache/corepack`을 설정하고 `pnpm run check:deferred`를 실행한다. `check → test:e2e → check:pilot`을 순차 실행하고 실패 시 멈추며 `.cache/verification/<시각>/`에 결과를 남긴다. 실행 전에 4173의 소유 프로젝트를 확인한다. 기존 preview를 재사용하려면 확인 뒤에만 `TRAVEL_APP_REUSE_PREVIEW=1`을 설정한다. 위 기본 자동 회귀는 새 원격 CI에서 통과했으나 추가 작성 항목과 전체 실데이터 검증을 대신하지 않는다.

추가 작성·실행할 회귀: 숙박 없는 귀국일, 이동일 복수 지역, 원천에 없는 본문/교통권/지도, 출처 미상 이미지, 장문 분할과 이어 읽기, 기존 메모/방문 체크/예약 override, 날짜별·장소 유형별 회화, 첨부 파일 링크/다운로드, 서로 다른 가이드의 동일 revision에서 Fact 갱신. 이 중 실제 통합본 조회·기존 상태 보존의 PC 증거는 있지만 모든 개별 회귀 픽스처를 작성한 것은 아니다. 16MiB/512KiB 행 경계는 `tests/exchange-limits.test.ts`의 생성/수신/빈 공간 복원 검사로 통과했다.
