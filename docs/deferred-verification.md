## 자동 회귀

`COREPACK_HOME=.cache/corepack`을 설정하고 `pnpm run check:deferred`를 실행한다. `check → test:e2e → check:pilot`을 순차 실행하고 실패 시 멈추며 `.cache/verification/<시각>/`에 결과를 남긴다. 실행 전에 4173의 소유 프로젝트를 확인한다. 기존 preview를 재사용하려면 확인 뒤에만 `TRAVEL_APP_REUSE_PREVIEW=1`을 설정한다. 위 기본 자동 회귀는 새 원격 CI에서 통과했으나 추가 작성 항목과 전체 실데이터 검증을 대신하지 않는다.

추가 작성·실행할 회귀: 숙박 없는 귀국일, 이동일 복수 지역, 원천에 없는 본문/교통권/지도, 출처 미상 이미지, 장문 분할과 이어 읽기, 16 MiB 출처 행·512 KiB 일반 행 경계, 기존 메모/방문 체크/예약 override, 날짜별·장소 유형별 회화, 첨부 파일 링크/다운로드, 서로 다른 가이드의 동일 revision에서 Fact 갱신.

## 실제 원천과 PC

- 지역별 9배치·귀국일·통합 43일의 입력/출력 수량·필드·독립 원천 대조를 실시한다. 변환 자체의 검사와 독립 검증을 구분한다.
- 원본/기존 G1·B-01 사본 해시를 재대조한다. 새 별도 프로필에서 DB 전체 행·첨부 해시·편집·재시작·오프라인 기록·빈 공간 복원을 검사한다. 사용자 검토 프로필을 테스트에 재사용하지 않는다.
- 실제 원천 변경 사본으로 B/L/R 재가져오기·보류·현지 편집/기록 보존을 검사한다. 전체 여행과 다른 여행의 전환을 확인한다.
- PC/모바일 viewport에서 SP-FR 탐색·목차·날짜 복귀·회화·본문/사진·저장소/백업·넘침·콘솔/외부 통신을 확인한다. 전체 43일 실제 화면의 사용자 확인을 받는다.
- 실행 지도 HTML은 파일로 보존했으며 내부 지도 조작·외부 지도 라이브 동작은 별도다. HTML 실행 시 네트워크 의존성도 구분한다.

## v2 AI

모의 provider로 조사→작성→제한된 보정→근거/초안 원자 저장·확인 적용을 검사한다. 특히 `StageAiProposal`의 전부 성공/전부 롤백, stale 기준·중복 요청·근거 충돌, 기존 예약/현장 필드 보존, 서버 재시작·브라우저 재진입·중단·저장 실패·1 MiB 초과를 검증한다. 실제 호출은 모델·예산·전송 범위 결정 뒤 별도 동의한 컨텍스트로만 수행한다. [구현 보고](phase-3-report.md).
