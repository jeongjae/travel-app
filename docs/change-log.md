# 후속 변경 목록·처리 이력

2026-10-30 · 관리: Codex · 사용자 요청: 경미한 문제는 기록하고 큰 기능을 먼저 진행

이 문서는 미해결 작업의 추적 목록이다. 보류를 수정 완료·요구 제외로 기록하지 않는다.
이슈의 크기는 재현 영향으로 판단한다. 데이터 손실·여행 간 누출·저장/복원 실패·stale 덮어쓰기·보안 문제는
경미한 항목으로 넘기지 않으며 해당 흐름을 고친 뒤 진행한다. 표의 재개 조건을 충족하면 후속 지시를 발행한다.
