## C 착수와 분리해 남기는 확인·운영 관문

아래는 경미한 결함으로 판정한 항목이 아니다. B 마감·실기기·운영 판정은 미완료로 유지하되 C 개발의 선행 조건에서 분리한다.

| VG-03 | 권리/외부 의존 검토·별도 매체 백업 | 해당 자료 재제공·운영 완료 판정 전. 실제 여행 자료를 공개 커밋하지 않음 |
