# P-08 중간 판정: 가상 구간 통과·실제 확대 보류

2026-10-22 · P-06 결과를 반영한 **잠정 판정**. P-07 실제 구간이 끝나지 않았으므로 P-08 최종 완료가 아니다.

재개 갱신: pnpm 전환 검증과 실제 원천 34파일 바이트 대조, 대표 전용 31파일 추출/콘텐츠 105개의 v2 후보 검증까지 진행했다. 실제 후보는 XLSX/미디어/나머지 필드 대응·누락 Fact 근거를 차단 항목으로 유지한다. [P-07 최신 보고](p07-report.md)를 따른다. 후보만으로 R-02나 실기기 기준을 통과 처리하지 않는다.

사용자 지정 실기기 대상은 **iPhone Chrome**이다. R-07~09의 기기 실행 결과·모델/iOS/Chrome 버전은 아직 없으며 미검증 상태다.

| 기준 | 현재 증거 | 판정 한계 |
|---|---|---|
| R-01 | 두 여행을 같은 프로그램에서 선택·편집·재시작, 독립 사본 보존 | 가상 표본 통과, 실제 원천은 미완료 |
| R-02 | 가상 AST/XLSX/본문/관계/첨부 추적, 실제 고정 원천 34파일 해시·대표 31파일 추출·v2 후보 105콘텐츠 | 실제 전체 필드/셀·첨부/표시·권리·격리 DB/UI 대조 미완료 |

추천 실행은 **P-06 가상 구간을 완료하고, 실제 대표 구간의 원천 대응·기기 검증을 먼저 채운 뒤 원본 범위를 확대**하는 것이다. 저장소 전체 1.51GB를 현재 ZIP/메모리 한도로 무조건 가져오거나, 출처/권리 확인 없이 첨부를 복제하지 않는다. 현재는 데이터가 실제 앱에 필요한 범위와 생성물/중복인지도 미검토이므로 파일별 제외 승인을 발명하지 않는다.

전체 이행 전 조건은 (1) F-03의 정확한 파일/셀/코드/관계/첨부 선택·원문 해시, (2) 미지원 필드의 명시적 해결과 표시 동등성, (3) 실제 휴대폰에서 설치·오프라인·현장 입력·백업 파일 보관/재선택·복원, (4) 측정한 첨부/메모리/용량에 따른 한도 조정이다. 미해결 자료를 원문 보관만으로 이행 완료로 세지 않는다.

[P-06](p06-report.md), [P-07](p07-report.md), [원래 대표 구간 기준](pilot-migration-plan.md)을 함께 따른다. 호스팅/서버 인증·v2의 실제 OpenAI 실행기·공개 운영 준비는 이번 백업/복원 판정에 포함하지 않는다.
