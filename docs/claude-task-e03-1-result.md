## 한 것

- **A 날짜 화면 "AI에게 요청"**: 날짜 화면 단추 줄(`day-toolbar`)의 "활동 추가" 옆. 과거 계획 버전을 보는 중과 v2가 아닐 때는 꺼진다. 누르면 "AI로 수정하기" 창이 범위 = 날짜 범위, 시작 = 끝 = 그 날짜로 열린다(전문 머리에 `- 범위: 날짜 ~ 날짜`). 창에서 넓히거나 "전체"로 바꿀 수 있고, 여행 메뉴의 "AI로 수정하기"는 그대로 전체로 열린다. 복사 안내 끝에 `돌아온 글은 "AI 결과 붙여넣기"로 가져오세요.`를 붙였다.
- **B 요청 종류**: 창에 "요청 종류"(자유 요청 / 빈 칸 채우기)와 편집 가능한 "요청 내용" 칸을 뒀다. 종류를 바꾸면 요청 내용이 그 종류의 글로 바뀌고(자유 요청은 비워 `[요청] (여기에 고칠 내용을 적으세요)` 자리 표시로 돌아감), 고친 글은 `[요청]` 줄에 반영된다. 양식·가져오기 코드는 바꾸지 않았다.
- **C 스타일 프리셋**: "AI로 계획 만들기" 빠른 설정 맨 위 "한 번에 채우기" 단추 3개. 관심사·속도(·방문)만 덮고 나머지는 그대로이며, "…로 관심사·속도를 바꿨습니다" 한 줄을 보인다. 값은 기존 선택지 안의 것만 쓴다.
- **D 지난번 답**: "요청서 복사"를 누르면 관심사·속도·예산·동행·인원·이동·숙소 유형·숙소에서 중요한 것을 `localStorage`(`travel-app.last-answers.v1`, 버전 1)에 남긴다. 여행지·날짜·방문·메모는 남기지 않는다. 읽기 실패·모양 불일치·선택지 밖의 값은 버린다. 있으면 "지난번 답 불러오기"와 "지난번 답 지우기"가 보이고, 불러오면 여덟 칸만 덮고 "지난번 답을 불러왔습니다(여행지·날짜는 그대로)"를 보인다. 준비 초안 안내 옆에 저장 위치 한 줄을 뒀다. "준비 초안 지우기"는 지난번 답을 지우지 않는다. 자동으로는 채우지 않는다.
