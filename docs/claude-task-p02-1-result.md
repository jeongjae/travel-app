# T-P2-1 결과 — 준비 자료 파일(가이드 + 고른 것 + 취향 답)

- 브랜치 `codex/p02-1-prep-file`(main `e6f2ce4` 기준). 지시서: [claude-task-p02-1-prep-file.md](claude-task-p02-1-prep-file.md)
- 사용자 확인 상태: **확인 대기**

## 구현

| 항목 | 내용 |
|---|---|
| 양식 | `src/guide-import/prep-file.ts` — `buildPrepFile` / `parsePrepFile`(순수 함수). `# 준비 자료:` 머리 → `## 취향 답` → `## 고른 것` → `## 가이드 원문`(저장된 가이드 글 그대로) |
| 취향 답 | `pickLastAnswers` 재사용, 8칸만. 빈 칸은 줄을 만들지 않음. 값 안의 `\|`는 `\\|`로 적고 읽을 때 되돌림 |
| 고른 것 | 종류·이름·지역으로 적고, 읽을 때 파일 안 가이드 항목과 세 값으로 맞춤. 맞는 것이 없거나 선택 이름을 모르면 버리고 건수를 셈. 같은 세 값의 항목은 모두에 적용 |
| 관대한 읽기 | CRLF, 줄 끝 공백, 둥근 따옴표(값 안), 글 전체를 싼 코드 블록 |
| 거절(한글 이유) | 양식 판 다름 / 가이드 원문 없음·가이드로 안 읽힘 / 표 제목·구분 줄·칸 수가 깨짐 / 크기 한도(가이드와 같음). 거절하면 초안은 그대로 |
| 구분 | 첫 내용 줄이 `# 준비 자료:`이면 준비 자료(`isPrepFileText`). 순수 가이드 글은 `parsePrepFile`이 `undefined`를 돌려 기존 경로로 감 |
| 화면 | 가이드 구역: **준비 자료 저장**(`준비자료-<목적지>.md`), **준비 자료 복사**, 안내 한 줄. 기존 가이드 입력(붙여넣기·클립보드·파일)이 준비 자료를 알아보고 미리보기 → 체크 2개(고른 것 기본 체크, 취향 답 기본 해제) → **준비 자료 반영**. 초안에 가이드가 있으면 "지금의 가이드와 고른 것 n건을 바꿉니다." 확인 |
| 계획 화면 | 준비 자료가 오면 `is-prep` 거절 + "준비 자료입니다. 'AI로 계획 만들기'의 가이드 칸에 넣어 주세요." (`is-guide`와 같은 방식) |

판단한 점(지시서에 없던 세부):
- 취향 답을 가져올 때 파일에 없는 칸은 현재 값을 **그대로 둔다**(파일에 적힌 칸만 덮어씀).
- 고른 것 건수는 파일의 줄 수가 아니라 반영 결과(항목 기준)로 센다.
- 표 구역이 통째로 없으면 빈 표로 본다(손으로 지운 글 허용). 제목 줄이 다르거나 칸 수가 틀리면 거절.
- 가이드 원문은 줄마다 앞뒤 공백을 다듬어 저장된다(기존 변환기도 줄 공백을 버리므로 해석 결과·key는 같음).
