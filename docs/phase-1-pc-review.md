# Phase 1 PC 표본 확인 안내

2026-10-23 · **G1 확인 대기**

별도로 연 최신 Chromium 검증 창에서 실제 3일을 조작할 수 있다. 자동 검증용 편집·기록은 다른 사본에만 남겼다.

## 여는 경로

- URL: `http://127.0.0.1:4173/?workspace=content&review=phase-1`.
- 여행: **SP-FR 대표 구간 Day 28·29·30**. 날짜 선택에서 3일을 전환한다.
- 상단의 **검증용 저장소** 표기를 확인한다. 평소 DB와 별도이며 기존 여행을 초기화하지 않았다.
- 이 창의 전용 프로필에 적재했다. 다른 브라우저에는 자동 공유되지 않는다. ‘여행 패키지 선택’에서 `local-data/p07/phase1-28-30/final-07/pilot.zip`을 골라 미리보기 후 ‘여행에 추가’를 누른다.
- 새 버전 안내가 보이면 편집을 저장한 뒤 ‘저장 후 새 버전 열기’를 누른다. 사이트 데이터 삭제로 새로 시작하지 않는다.

## 확인할 동작

1. **일정:** 날짜를 바꿔 핵심·식사·교통·대안, 활동의 메뉴/예약·원천 상태, 이동/숙박을 본다. 날짜별 ‘숙소·지도·원천 보충’도 연다.
2. **장소·지역:** 본문 3절·사진·Fact 상태를 본다. 지역 안내의 생활·교통 버튼을 연다. 외부 근거 누락의 ‘검토 필요’는 의도된 표시다.
3. **예약·할 일:** 코드/통합문서 출처·원천 위치·상태·다음 행동을 본다. 같은 이름도 ID가 달라 별도 대조본으로 남긴 항목이 있다. 7건의 실제 예약 확정으로 합산하지 않는다.
4. **준비·회화:** 발음/표지·회화, ‘운영 통합문서 · 12시트 대조’, ‘사진·관광 지도 · 오프라인 자료’를 연다. 46파일은 46장의 독립 사진 수가 아니다. 전체 필드 대응표도 JSON으로 내려받을 수 있다.
5. **편집·기록:** ‘실용 편집’으로 문장을 저장하고 새로고침 후 다시 본다. 검증용임을 적은 기록/메모를 저장·재조회한다. 실제 여행 기록과 구분되는 표현을 사용한다.
6. **백업:** ‘저장소·백업’에서 전체 백업을 만들고 파일로 저장한다. 재선택·복원은 아래 빈 공간에서 수행한다. 검토 사본을 지우지 않는다.

빈 복원 공간은 `http://127.0.0.1:4173/?workspace=content&review=phase-1-restore`다. 다른 탭에서 ‘저장소·백업’ → ‘전체 백업 파일 선택’ → 미리보기 → ‘확인 후 전체 복원’을 수행하고 편집/기록/사진을 재조회한다. 이미 여행이 있는 공간이면 review 이름 끝에 다른 짧은 영문·숫자를 붙여 새 검증 공간을 만든다.

네트워크 차단·재실행·복원은 개발자가 실제 표본으로 자동 검사했다. 직접 확인할 때는 PC 전체 통신 대신 브라우저 개발자 도구의 Network 오프라인을 사용할 수 있다. iPhone 검증은 별도다.

## 재실행과 피드백

창을 닫았다면 저장소 폴더의 PowerShell에서 같은 전용 프로필을 다시 연다. 4173에 이 프로젝트의 preview가 실행 중이어야 한다.

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = Join-Path (Get-Location) '.cache/ms-playwright'
node scripts/open-pilot-review.mjs --package local-data/p07/phase1-28-30/final-07/pilot.zip --output-dir local-data/p07/phase1-28-30/user-review-final
```

**확인 완료** 또는 **수정할 날짜/화면/내용**을 알려 주면 된다. 문서·자동 검사만으로 G1이나 전체 이행 완료를 처리하지 않는다. [검사·기술 판단](phase-1-report.md), [지역별 후속 작업표](../local-data/p07/phase1-28-30/regional-batches.md)를 함께 볼 수 있다. 실제 자료는 로컬 전용이어서 GitHub에서는 후속 작업표 링크가 열리지 않는다.
