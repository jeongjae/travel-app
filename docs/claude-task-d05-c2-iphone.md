## 3. C3 실제 여행 선별 호출 (G-D·G-P·G-B 통과 뒤에만)

시작 전 확인표(결과 문서에 적는다): G-T(43일 여행·날짜 제한 없음·기록 미포함·2단계 적용) · G-P · G-B 통과 시각 · OpenAI 대시보드의 당일 사용액(사용자가 읽어 줌) · 일일 한도 잔여.

1. **1단계 — PC, 사본**: 검토 공간 `?workspace=content&review=d05-real`에 실제 패키지(`local-data/`)를 가져온다. 요청 2회 — ① 추가 1건 요청 → **거절**, ② 수정 1건 요청 → **적용**. 매번 사용자가 전송 미리보기를 읽고 동의 단추를 누른다. 평소 공간의 계획 revision이 바뀌지 않았음을 확인한다.
2. **2단계 — iPhone Chrome, 평소 공간**: 요청 1~2회. 적용은 **추가(add) 1건**만 한다. 적용 전 계획 버전 번호 → 적용 뒤 번호 → "계획 버전"에서 이전 버전 조회 가능 → 사용자가 화면에서 그 항목을 **삭제**해 원래 일정으로 돌림 → 최종 일정이 적용 전과 같은지(항목 수·해당 날 목록) 확인.
3. 호출마다 기록: 날짜 범위(일 수), 미리보기 항목 수(날짜·활동·장소·기록), 토큰(입력·출력), 웹 검색·도구 항목·검색 동작 수, 추정 금액, 검증 거부·재작성 횟수, 출처 수와 종류 분포, "변하는 사실" 표시 유무, AI 작업 기록 목록과 화면 사용량의 일치 여부(CL-38), `web_search_call` 대 대시보드 도구 호출 수(CL-37), 해당 시 CL-29.
