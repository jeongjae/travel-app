# C-07 삿포로 가상 여행 · 사용자 수행 대본 (T-C8)

2026-10-30 · **자동 리허설 통과 / 사용자 수행 확인 대기** · 확인 기록은 [c07-user-check.md](c07-user-check.md)

> 가상 여행입니다. 장소·설명·일정은 모두 지어낸 자료이고 요금·운영 시간은 확인하지 않았습니다(화면에도 "가상 메모·미확인"으로 적습니다).
> 실제 예약·실여행·iPhone 확인·배포 승인이 아닙니다. 같은 대본을 [`tests/e2e/c07-sapporo.spec.ts`](../tests/e2e/c07-sapporo.spec.ts)가 PC·모바일 에뮬레이션으로 먼저 통과했습니다.
> 시험 통과는 사용자 확인이 아닙니다. 화면이 대본과 다르면 그 단계를 `c07-user-check.md`에 적어 주세요.

## 준비

1. 터미널에서 `pnpm run build && pnpm run preview:ui` 를 실행합니다(4173 포트).
2. PC 브라우저에서 **검토 공간**을 엽니다. 평소 쓰는 공간을 쓰지 않습니다. 이름은 새로 정합니다.
   `http://127.0.0.1:4173/?workspace=content&review=sapporo-2026`
3. 화면 안내 문구 "검증용 저장소"가 보이면 비어 있는 검토 공간입니다. 이미 여행이 있으면 `review=` 이름을 바꿔 다시 엽니다.

공통 입력: 여행 이름 **삿포로 연말 가상 여행** · 기간 **2026-12-31 ~ 2027-01-03**(4일·3박) · 시간대 **Asia/Tokyo**.
날짜 입력 상자는 직접 숫자를 쳐도 됩니다. 메뉴 이름은 화면의 단추 글자 그대로 적었습니다. 위쪽 접힌 영역은 `여행 목록`(여행 선택·새 여행)과 `더 보기`(실제 기록 등)입니다.

## S6 · 두 여행 백업과 빈 공간 복원 (C-S6)

기존 여행은 아래 둘 중 하나를 고릅니다. **기본은 A(가상)** 입니다.

- **A. 가상 여행(기본)**: 여행 목록 → `가상 여행 둘러보기` → "가상 산책 여행 A · 3일" → `여행에 추가`.
- **B. verified ZIP 사본(선택)**: 원본 `local-data/phase2/verified-package-20261026/pilot.zip` 을 **복사한 사본**만 씁니다. 원본을 열거나 옮기지 않습니다.
  1. PowerShell: `Copy-Item local-data\phase2\verified-package-20261026\pilot.zip local-data\c07-user\pilot-copy.zip` (폴더는 미리 만듭니다. `local-data/`는 Git 제외 경로입니다.)
  2. 해시 확인: `(Get-FileHash local-data\phase2\verified-package-20261026\pilot.zip -Algorithm SHA256).Hash` 가 `d183228064312c2a69d27018f5cfc6f5c909e262d621890f101770049274bbe0`(84,453,766바이트)와 같은지, 사본 해시도 같은지 확인합니다. 다르면 중단합니다.
  3. 여행 목록 → `여행 패키지 선택`에서 사본을 고르고 `여행에 추가`.
