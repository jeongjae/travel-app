## 미검증·남은 후보

- 실기기·사용자 화면 확인 없음. 평소 공간(실제 가져온 데이터)에서의 확인은 사용자 몫.
- 지역 파일명 해석은 `NN_Name_vX.md` 규칙에 의존한다. 이 패키지 9곳은 모두 지역 이름으로 연결됐다.
- 기록 탭 메모에 `원천 대상 stay:Nice · …`처럼 원천 키가 보이는 문구가 남아 있다(저장된 메모 본문, 이번 범위 밖).
- 여행 이름 바꾸기는 저장 명령이 필요해 하지 않았다.
