1. `check:deferred`가 `npm_execpath`를 무조건 Node 스크립트로 실행해 Windows의 `pnpm-native.exe`에서 검사 전에 실패했다. `.exe`는 직접 실행하고 JS 엔트리는 Node로 실행하도록 수정했다. 수정 후 실제 세 단계가 모두 실행되는 것을 확인했다. 커밋 `4437852`, origin/main push 완료.
