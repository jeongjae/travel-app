# U4 삿포로 가상 여행 · 축약 수행 대본 v2

2026-11-04 · **자동 리허설 통과 / 사용자 수행 확인 대기** · 확인 기록은 [u4-user-check.md](u4-user-check.md) · 목표 소요 **30분 이내**

> 가상 여행입니다. 장소·설명·일정은 모두 지어낸 자료입니다. 실제 예약·실여행·iPhone 확인·배포 승인이 아닙니다.
> 한 번의 수행으로 **Q-U2(입력 폼)·Q-U3(읽기 화면)·S6-d(복원 안내)**를 함께 확인합니다. 같은 대본을 [`tests/e2e/u4-sapporo.spec.ts`](../tests/e2e/u4-sapporo.spec.ts)가 PC·모바일 에뮬레이션으로 먼저 통과했습니다. 시험 통과는 사용자 확인이 아닙니다.
> 이전 대본([c07](c07-sapporo-scenario.md))과 [사용자 기록](c07-user-check.md)은 그대로 보존합니다. 화면이 대본과 다르면 그 단계를 `u4-user-check.md`에 적어 주세요.
> 스크린샷은 `docs/design/ui-u4/`에 PC(`-desktop`)·모바일(`-mobile`)로 있습니다. 화면이 다르면 각 절의 그림과 비교하세요.

## 준비

1. PowerShell에서 저장소 폴더로 이동해 `pnpm run build; if ($?) { pnpm run preview:ui }` 를 실행합니다(4173 포트). 서버 창은 끝날 때까지 열어 둡니다.
2. PC 브라우저에서 **새 검토 공간**을 엽니다: `http://127.0.0.1:4173/?workspace=content&review=sapporo-u4`
3. "검증용 저장소"가 보이는 빈 공간이어야 합니다. 이미 여행이 있으면 `review=` 이름을 바꿉니다.

공통 입력: 여행 이름 **삿포로 연말 가상 여행** · 기간 **2026-12-31 ~ 2027-01-03** · 시간대 **Asia/Tokyo**. 아래 탭은 `오늘`·`일정`·`가이드`·`기록`·`더보기`입니다.
