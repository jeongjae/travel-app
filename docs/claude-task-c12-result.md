## 1. 변경 요약
- **C8 오늘**: 같은 날 실제 기록을 타임라인에 표시. 계획 카드에 최신 기록 배지(`방문 14:20`/`건너뜀`), 계획에 없는 기록(예정 외·제거된 항목의 기록)은 점선 기록 카드(`예정 외`, `정정`·`기록 탭에서 보기`만). 시각 순 삽입, 시각 없음은 맨 아래. 저장 알림 문구 변경. `plan_items`·계획 버전 불변.
- **C5 기록 목록**: 날짜 머리(`6월 2일 (수)`) 아래 시각 순, 발생일 미상 별도. 정정 체인은 최신본 1행 + `정정 N회 · 원문 보기` 접기, 정정 버튼은 최신본만. `기록 당시 내용`·`앱에 남긴 시각`은 `⋯`. 정밀도·시간대는 보조 문구.
- **C6 회고**: 버전 이름 `MM/DD HH:mm · 이유 · 계획 N`(현재는 `현재 계획 (MM/DD HH:mm)`), 열 머리 동일. 항목 배지 추가/제거/이동(날짜)/시각 변경/내용 변경. CL-14: 날짜 제목·이동·숙박 변경도 `changed`. 설명문 3종은 ⓘ 접기. 모바일 열 머리 `sticky`.
- **C7 가이드**: 지역 머리(이름·한 줄 소개·지역 가이드 N개·장소 N곳) → 장소 목록 → 지역 없는 장소. 검색은 묶음 필터, 0건이면 `검색어 지우기`. 사진 카드 격자 제거(상세에는 유지), 죽은 `GuideCard` 삭제.
- **D2**: `오늘`·`기록`(회고 포함) 최대 폭 672→880px. 스크린샷상 가독성 문제 없어 유지(되돌릴 이유 없음).

## 3. 선택자 대응표 (단언 유지)
| 이전 | 이후 |
|---|---|
| `정정 N/M단계…`·`정정된 기록 · 원본 보존` 바로 보임 | `정정 N회 · 원문 보기` 접기를 연 뒤 같은 문구 단언(field-records·c07·content·ui-u2) |
| 정정 체인 행 수 = 단계 수(`장소 · … (기록 당시 이름)` 3회) | 체인당 1행(1회). 단계 문구는 접기 안 |
| `기록 당시 내용` 바로 클릭 | `기록 더 보기`(⋯) 먼저 |
| `과거 계획 N · 이유` 옵션 라벨 | `MM/DD HH:mm · 이유 · 계획 N`(이유 포함 옵션 검색) |
| `변경 이유(계획 전체): …` | `변경 이유: …`(현재 열), 계획 전체 설명은 ⓘ |
| `.guide-card` / 지역 버튼 0건 | `.guide-place-row` / 검색 결과의 지역은 일치 장소를 담는 머리로 남음(`section.guide-region` 1개) |
| `2032-06-01 14:20 · Asia/Tokyo` | 날짜 머리 `6월 1일 (화)` + `14:20` + 보조 `현지 시각 · Asia/Tokyo` |
| `.day-timeline h3` / `.timeline-time` | `article.timeline-stop` 범위(기록 카드 제외) |
| 제거한 항목의 건너뜀 후 제목 0건 | 계획 카드 0건 + 같은 날 기록 카드 1건(C8) |
