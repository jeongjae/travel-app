## CL-14 · 날짜 변화 표시 범위(이번 수용 비차단)

reasonOf의 dayChange는 해당 날짜 활동만 비교한다. 날짜 title만 바꾸고 활동을 유지한 두 계획으로 추가 검사했을 때
기대 changed와 달리 unchanged가 나왔다. UI는 ‘이 날짜는 직전 버전과 같습니다’라고 써 비교 범위보다 넓게 설명한다.
숙박/이동·날짜 메타 변경도 같은 비교 공백이 있다(소스 확인). 계획 열의 실제 값이나 저장 데이터가 바뀐 것은 아니다.
