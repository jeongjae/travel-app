## 기술 판단과 실행

- 숙박 없는 귀국일에 숙박 지역을 만들지 않는다. 이동일의 장소 frontmatter/Fact에 명시된 지역을 맥락 지역으로 포함한다. 지역 원천의 모든 독립 본문도 명부/Fact와 함께 선택한다.
- 없는 교통권 목록·관광 지도는 빈 목록으로 보존한다. 명시적 null·잘못된 형식은 기존 검증을 통과해야 한다. 본문 부재를 새 설명으로 채우지 않는다.
- 사진2그룹의 원본 주소/권리 미확인과 실행 지도의 권리 미확인을 보존했다. 웹 근거를 발명하지 않고 고정 원천 위치를 근거로 사용하며 ‘미확인’을 표시한다. 공개 재배포 허락을 판단한 것이 아니다.
- 일반 행 한도512 KiB를 유지하고 긴 원천 보충 본문을 절 경계에서 나누어 이어 읽기 링크를 제공한다. 전체 이행의 출처/기준 값이 4 MiB를 넘어 출처 행만16 MiB로 구분했다. 이 변경의 백업·복원 경계 테스트는 후속이다.
- 메모의 저장 시각·원천 ID·작성자는 대조 본문에 보존한다. 방문/실행 체크는 `legacy-state`로 옮기고 실제 발생 시각을 만들지 않는다. 두 숙박 메모는 앱 예약 연결이 불명확해 원천 대상명을 적은 여행 메모로 보존했다. 원천 예약 override는 명시적인 XLSX ID로만 연결한다.
- 공통 안내3개·지역 장문9개, 코드의 예약19건·긴급 안내·예약 진행/원칙/체크리스트4본문과 날짜별/장소 유형별 회화 추천을 데이터로 옮겼다. 렌더러를 실행하지 않고 AST 상수/명시적인 정적 본문만 읽었다.
- Fact 바인딩과 명시적인 원천 본문 링크를 연결했다. 원천 `|x2` 수식은 기본 Fact와 ‘원천 수식·자동 계산 미적용’ 표기로 보존한다. 링크의 실행 지도 HTML/GeoJSON/KML은 원본 바이트 첨부로 내려받게 하며 HTML을 앱 안에서 실행하지 않는다.
- 기기 준비 표시, 날짜/장소 회화, 가이드별 Fact 재조회, 이미지 지연 로딩을 보완했다. 원천 공통/장문 안내는 ‘준비’의 읽기 자료에서 접근한다. 실제 화면 테스트는 아직이다.

## 대응 범위와 남은 확인

선택 추출 leaf35,667개는 표시35,134·메타533·보류0·미대응0이다. 이는 고정 입력에 대한 대응이며 SP-FR 저장소의 모든 빌드 코드·정책 문서·옛 산출물을 전부 DB화했다는 뜻이 아니다. 일반 렌더러 문구·알고리즘은 공통 프로그램의 책임으로 구분한다. `input/audit.json`의 렌더 함수별 문자열 목록을 보존했으며, 명시적 정적 안내 외의 렌더러 잔여 여행 콘텐츠 여부는 독립 검토에서 재확인한다.

포맷·린트·타입·프로덕션/PWA 빌드는 통과했다. 단위/E2E/브라우저 실제 적재·전체 복원·독립 원천 대조·실제 B/L/R·사용자 화면 확인은 이번 요청에 따라 미실행이다. [일괄 검증 목록](deferred-verification.md), [iPhone 절차](phase-2-prime-runbook.md), [v2 AI 구현](phase-3-report.md)을 따른다. G2 전체 확인은 아직 닫지 않는다.
