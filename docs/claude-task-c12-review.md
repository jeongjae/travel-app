## 2. 후속(차단 아님 → C-13)

- **R1 날짜 머리 겹침**: `.record-day > h3`가 `sticky; top: 0`이고 상단 바 `.journey-topbar`도 `sticky; top: 0; z-index: 20`. 실제 스크롤에서 날짜 머리가 상단 바 뒤로 들어가 보이지 않는다. 스크린샷(`after-mobile-records.png`)의 중간 상단 바는 스크롤 상태 전체 캡처의 흔적이지만 근본 원인은 같다. 상단 바 높이만큼 내려 붙인다.
- **R2 다른 날로 정정된 기록의 배지**: `RecordBadge`는 시각만 보여 준다. 삿포로 S4처럼 12/31 계획 "카운트다운 산책"을 1/1 00:30으로 정정하면 12/31 카드에 `방문 00:30`으로 보이고 1/1 타임라인에는 아무 흔적이 없다. 날짜가 다르면 배지에 날짜를 붙이고, 실제 날짜의 타임라인에 `12/31 계획 항목의 기록` 카드를 둔다.
- Claude 남은 후보: 회고 `ⓘ` 작음, `⋯` 펼침 시 줄바꿈, 가이드 장소 썸네일 제거 → C-13에서 처리.
