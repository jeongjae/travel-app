## 3. CL-39(AI 개편)에 넘길 관찰 — 사실만

- 변경 요청 원문은 웹 검색에 보내지 않는다. 요청이 가리킨 장소의 운영시간을 조사하려면 미리보기의 조사 질문을 사용자가 고쳐야 했다(C3 2회차, T-D4 관찰 2와 같은 양상).
- 장소 연결이 없는 활동은 자동 조사 질문에서 빠졌다(CL-42, 원인 추정).
- 3회차 변경안이 카페 활동을 13:30~13:30(길이 0)으로 바꿔 점심과 겹쳤고 검증이 통과시켰다. 사용자 불만족(CL-43).
- 2회차는 응답 형식 해석에서 실패했고 원인 위치가 남지 않았다(이후 `a3fcac5`로 위치 코드 기록).
- 1회차 미리보기가 사용자가 읽기 전에 지나갔다(CL-44).
- T-D4 1회차: 근거 부족 시 모델이 빈 제목 `add`를 보냈다.
