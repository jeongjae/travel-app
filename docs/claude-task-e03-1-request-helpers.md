## A. 날짜 화면의 "AI에게 요청"

**[확정]** 그 날짜만 담아 연다. 창에서 범위를 넓힐 수 있다.

1. 날짜 화면의 단추 줄(`day-toolbar`, "활동 추가" 옆)에 **"AI에게 요청"** 단추를 둔다. 과거 계획 버전을 보는 중(`historical`)에는 끈다.
2. 누르면 기존 "AI로 수정하기" 창(`UpdateExport`)을 **범위 = 날짜 범위, 시작 = 끝 = 그 날짜**로 채워 연다. 나머지(전문 보기, 글자 수, 예약 메모 제외, 복사·파일 저장)는 그대로다. 사용자가 창에서 날짜를 넓히거나 "전체"로 바꿀 수 있다.
3. 돌아온 글은 지금처럼 "AI 결과 붙여넣기"로 받는다. 복사 뒤 안내 문구에 그 단추 이름을 그대로 적는다.
4. 여행 메뉴의 "AI로 수정하기"는 지금처럼 "전체"로 열린다.

## B. "빈 칸 채우기" 요청문

**[확정]** "AI로 수정하기" 창에 요청 종류를 고르는 칸을 둔다: 자유 요청 / 빈 칸 채우기.

1. 요청 종류 `자유 요청`(기본, 지금과 같음) · `빈 칸 채우기`. A로 연 창에도 같이 있다.
2. `빈 칸 채우기`를 고르면 `[요청]` 줄이 아래 뜻의 글로 채워진다(문장은 다듬어도 되고, 최종 문장을 결과 문서에 적는다):
   - 일정의 시간·제목·순서는 바꾸지 말고, 비어 있는 **메모·링크** 칸만 채운다.
   - 장소 칸이 비어 있는 활동에 맞는 장소가 있으면 장소 칸에 이름을 적고, `## 장소` 표에 **ID 없는 새 줄**로 설명·영업시간·링크를 적는다.
   - **ID가 있는 장소 줄은 고치지 않는다**(앱이 기존 장소의 내용은 글로 받지 않는다 — E2-B 보완 4번).
   - 확인되지 않은 것은 채우지 말고 코드 블록 밖에 따로 적는다.
3. 사용자는 채워진 글을 창에서 고칠 수 있다. 요청 종류를 다시 바꾸면 사용자가 고친 글을 덮기 전에 묻지 않고 바꾼다(되돌리려면 다시 고르면 된다) — 단, `자유 요청`으로 돌아가면 빈 자리 표시(`[요청] (여기에 …)`)로 돌아간다.
4. 양식·가져오기 쪽은 바꾸지 않는다. 이 요청으로 돌아온 글이 지금의 검사·미리보기를 그대로 통과해야 한다.

## C. 스타일 프리셋

**[확정]** 첫 방문 핵심 관광 · 여유로운 휴식 · 미식 중심, 세 가지로 시작한다.

1. "AI로 계획 만들기"의 조건·취향 구역 맨 위에 "한 번에 채우기" 단추 세 개를 둔다.
2. 프리셋은 **취향 쪽 세 칸만** 채운다. 여행지·날짜·동행·인원·예산·교통·숙소·메모는 건드리지 않는다.

   | 프리셋 | 관심사(`interests`) | 속도(`pace`) | 방문(`visit`) |
   |---|---|---|---|
   | 첫 방문 핵심 관광 | 관광, 문화예술 | 보통 | 처음 |
   | 여유로운 휴식 | 휴식, 자연 | 여유 | (그대로) |
   | 미식 중심 | 미식, 관광 | 보통 | (그대로) |

3. 누르면 위 칸의 기존 값을 덮는다. 누른 뒤 "관심사·속도를 바꿨습니다" 같은 한 줄을 보여 주고, 칸은 그대로 고칠 수 있다. 값은 `travel-brief.ts`의 기존 선택지(`INTEREST_OPTIONS`·`PACE_OPTIONS`·`VISIT_OPTIONS`) 안의 것만 쓴다.

## D. 지난번 답 불러오기

**[확정]** 자동으로 채우지 않고 "지난번 답 불러오기" 단추로 불러온다.

1. 요청서를 **복사하거나 파일로 저장할 때**, 그때의 답 가운데 여행마다 달라지지 않는 것을 기기 설정에 "지난번 답"으로 남긴다: 관심사, 속도, 예산, 동행, 인원, 교통, 숙소 종류, 숙소에서 중요한 것. **여행지·날짜·방문(처음/재방문)·메모는 남기지 않는다.**
2. 저장 위치는 준비 초안과 같은 방식(`localStorage`, 새 열쇠 이름, 버전 번호 포함, 읽기 실패·모양 불일치는 버리고 없는 것으로 본다 — `guide-import/draft.ts`의 방식). 백업에 들어가지 않고 다른 기기로 옮겨지지 않는다는 안내를 준비 초안 안내 옆에 한 줄로 둔다.
3. "지난번 답"이 있으면 조건·취향 구역 위에 **"지난번 답 불러오기"** 단추가 보인다. 누르면 위 여덟 칸을 지난번 값으로 덮고 "지난번 답을 불러왔습니다(여행지·날짜는 그대로)"를 보여 준다. 없으면 단추가 보이지 않는다.
4. "지난번 답 지우기"를 둔다(작은 단추). "준비 초안 지우기"는 지난번 답을 지우지 않는다.
5. 준비 초안이 이미 있는 상태에서도 단추는 덮어쓴다(누른 사람의 뜻). 자동으로는 어떤 경우에도 채우지 않는다.

## 시험

- 단위: 프리셋이 세 칸만 바꾸는지 / 지난번 답의 저장 대상·제외 대상 / 깨진 저장 값 버리기 / 빈 칸 채우기 요청문 생성.
- E2E(desktop·mobile): A — 날짜 화면에서 열면 범위가 그 날짜이고 전문 머리에 `- 범위:`가 있다, 과거 버전에서는 꺼져 있다 / B — 요청 종류를 바꾸면 `[요청]` 줄이 바뀐다 / C — 프리셋을 눌러도 여행지·날짜가 그대로다 / D — 복사 뒤 초안을 지우고 다시 열면 "지난번 답 불러오기"가 보이고, 누르면 여덟 칸이 채워지고 여행지는 비어 있다.
- 기다림은 저장·전환이 끝나야 생기는 요소로 한다(11/19 교훈).
- 캡처(PC·390px): 날짜 화면 단추 줄, 요청 종류 칸, 프리셋·불러오기 단추 줄.
