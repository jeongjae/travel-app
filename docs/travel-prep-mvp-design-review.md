## 사실 (코드·문서 대조)

- 부록 B의 "확인" 4건은 맞다(의존성, `planLeg`의 활동 연결, ID 형식, 저장 명령 3종).
- 계획 검증은 활동의 `placeLinks`가 가리키는 장소가 계획의 참조 목록에 있어야 통과시킨다(`validate.ts`). 새 여행은 콘텐츠 없이 만들어진다 → 새 여행의 첫 계획이 새 장소를 바로 가리키기 어렵다(명령 처리 전체는 정독하지 않음).
- `planStaySchema`에는 지역·예약 원문을 담을 칸이 없다.
- P0 가이드 시험은 아직 수행되지 않았다.
