# Phase 2 · 지역별 이행

2026-10-23 · **B-01 Barcelona 실행 중** · G1 사용자 확인 완료

## 착수와 범위

사용자 ‘계속 진행’에 따라 Phase 2를 시작한다. 작성자는 지역별 작업표 순서의 Barcelona Day 1~3을 첫 배치로 선택했다. 일정 17활동·14이동·9개 연결 장소를 기준으로 시작하고, 지역 가이드에만 등장하는 장소도 원천 명부/Fact/본문을 대조해 포함 여부를 추적한다. 조사 초안의 총량을 확정 이행 수량으로 쓰지 않는다.

기준 원천은 `35498adc6413dad45922f2dab87781afeb04d898`다. 기존 Phase 1 읽기 사본·ZIP·검토 프로필은 보존하고 Phase 2는 별도의 비공개 소스/실행 폴더와 검증 DB를 사용한다. 기존 앱 편집본에 무확인 적용하거나 표본 여행을 전체 여행으로 덮어쓰지 않는다.

## 기술 판단과 실행 순서

1. 원천 목록·Git blob/크기/SHA-256을 고정하고 지역 명부·Fact·본문·일정 참조를 대조한다. 원본 모듈을 실행하지 않는다. 독립 본문이 없는 명부 항목은 누락 여부와 표현 방법을 명시한다.
2. 기존 변환기의 Day 28~30 전용 경로·계보·검증 URL을 배치 설정으로 구분한다. 원천 밖을 제외한 것처럼 처리하지 않고 다음 배치/미지원 사유로 추적한다.
3. 첨부 바이트·출처/권리 표기·본문 관계를 확인한 뒤 ZIP→격리 DB→화면→편집/오프라인/전체 복원을 검증한다. 가상 회귀에는 실제 원문·예약·사진을 넣지 않는다.
4. 실제 화면을 사용자에게 제시하고 **B-01 확인**을 받은 뒤 다음 지역으로 간다. G2 전체 확인과 iPhone 실기기 검증은 별도다.

PC 우선 결정은 유지한다. U-04의 실기기 접속·파일 전달 범위는 미결정이며 기기 접속·배포는 시작하지 않는다. 작업은 검토 가능한 단위별로 커밋·GitHub push한다.

## 검증·산출물·완료 관문

현재는 원천 조사·도구 일반화 단계다. 후속 실행 결과의 입력/정규화 수량·본문·첨부·대응표·ZIP/DB 대조·화면 URL·GitHub 커밋을 이 보고서에 갱신한다. 기존 119개 단위·38개 화면 회귀를 이번 배치의 검증 완료로 재사용하지 않는다.

실제 자료는 `local-data/phase2/` 하위에만 두며 커밋하지 않는다. 현재 B-01은 **검토 준비 중**, 사용자 확인은 아직 없다. 전체 43일·9지역·166장소 이행 완료를 뜻하지 않는다.
