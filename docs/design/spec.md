# 첫 UI 디자인 명세

Imagegen 기본 도구로 생성한 `itinerary-concept.png`를 구현 참조로 선택했다. 사용자 승인으로 기록하지 않는다. 프롬프트의 목적: 한국어 개인 여행 계획·실제 기록 UI, 전체 화면, 흰 배경, 녹색 강조, 왼쪽 여행 목록, 위쪽 탭, 열린 타임라인, 오른쪽 계획 보존 안내. 실제 생성 결과 크기는 1505×1045이다.

토큰: background #ffffff, ink #20332d, primary #2d6553, selected #edf4ef, border #e4e9e6. 한국어 시스템 sans, 본문 16px, UI 14–16px, 큰 제목 28–32px. border 1px, radius 8–12px. 별도 폰트/CDN 이미지 호출 없음.

레이아웃: rail 224px(참조의 상대 폭을 실제 화면 밀도에 맞춤), main 32px 패딩, 날짜별 타임라인 + 280px 안내. 1000px 이하 안내를 아래로, 700px 이하 rail을 위쪽 여행 선택으로 변경. 44px 이상 터치 대상, 탭 가로 스크롤, 키보드 포커스 표시.

화면의 파리/서울 데이터는 가상 예시이며 사용자가 '예시 여행 불러오기'를 선택할 때만 저장한다. 기본은 빈 상태다. 일정 추가·수정·실제 기록·정정·변경안 검토·여행 생성은 같은 스타일의 네이티브 dialog/폼으로 구성한다.

기능상 필요한 의도적 확장: 빈 상태, 오류/저장 상태, 버전별 조회, 근거 상세, JSON 파일 미리보기, 실제 시각·시간대 입력, 예정 외 기록, AI 컨텍스트 내보내기. 원본 UI 이미지의 고정 텍스트 대신 실제 선택 여행 데이터·revision·저장 상태를 표시한다. 실제 AI가 연결되지 않은 상태를 분명히 표시한다.
