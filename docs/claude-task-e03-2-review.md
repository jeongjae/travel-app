### 수정 지시 R1 (`codex/e03-2-place-edit`에 이어서)

1. 기준 연결은 **끊김 없이 이어진 우리 저장**에만 준다. 이 화면이 한 저장마다 "저장 전 revision → 저장 후 revision"을 기록하고, 다음 저장의 "저장 전"이 직전 저장의 "저장 후"와 같을 때만 구간을 잇는다. 장소 만들기 → 장소 수정 사이, 장소 수정 여러 건 사이, 장소 만들기의 묶음 사이 모두 같은 규칙이다.
2. 끊긴 것을 알게 되면 연결을 버린다(`revisionBridge` 없음) → 같은 글은 "오래된 글"로 막힌다. 이미 저장한 장소는 남는다고 안내한다(지금의 문구 방식 그대로).
3. 시험(단위, 실제 저장소): 장소 만들기 뒤 다른 저장(예: 활동 메모 수정) → 장소 수정 → 같은 글이 **막힌다** / 장소 수정 2건 사이에 다른 저장 → 막힌다 / 끼어든 저장이 없으면 지금처럼 이어진다. 구간을 잇는 판단은 화면에서 떼어 순수 함수로 두고 그것을 시험한다.
4. 화면·문구·다른 동작은 바꾸지 않는다. `pnpm run check` 뒤 push, CI 통과 확인 후 보고한다(로컬 전체 E2E는 포트가 비어 있으면 돌린다).
