# P-04 중간보고: 공통 가이드 조회·본문 편집

2026-10-22 · P-04 범위 구현·검증 완료

## 구현 범위

- `?workspace=content`의 공통 React 화면을 추가했다. 기존 일정 화면은 유지하고 상단 링크로 이동한다. 새 코드/Markdown/ZIP 라이브러리는 화면을 열 때 지연 로딩한다.
- 여행 패키지 검증 미리보기→명시적 추가, 두 여행 선택, 날짜별 일정/숙박/이동, 장소·지역 탐색/이름·지역 검색, 장소 본문 3섹션/GFM 표/Fact·내부 링크/로컬 첨부, 예약/작업/지도 외부 링크, 생활·교통·언어 안내와 회화를 데이터로 표시한다.
- 현재 콘텐츠 head 조회와 선택 계획/실제 기록의 고정 context 조회를 구분한다. Fact의 원천 신뢰/확인일·앱 검토 상태를 표시하고 수집을 확인 완료로 취급하지 않는다.
- 기존 장소 섹션 편집/미리보기는 처음 연 trip/document revision을 보관한다. 저장 시 새 불변 revision/head/receipt만 바꾸며 계획·실제를 수정하지 않는다. 두 탭 충돌 시 편집 폼과 입력을 유지한다.
- v1 브라우저는 기존 여행의 변환 보고를 확인한 후 명시적 전환할 수 있다. 빈 브라우저에서 임의 여행을 자동으로 넣지 않는다. 새 여행은 공통 기간/일자 데이터로 만든다.

## 자율 선택과 근거

| 항목 | 실행한 방안 |
|---|---|
| 기존 앱 진입점 | 기본 기존 화면을 보존하고 ‘여행 가이드 열기’로 새 화면에 진입한다. 기존 사용자의 데이터를 자동 전환하거나 UI를 갑자기 바꾸지 않는다. |
| 본문 | react-markdown/GFM + raw HTML 비표시 + 검증된 fact/link/asset 바인딩으로 표시한다. 임의 코드/MDX를 실행하지 않는다. 실제 HTML 지원 노드 변환 대조는 P-07에 남긴다. |
| 과거 조회 | 계획 선택을 명시하면 현재 계획 ID와 같더라도 저장 당시 context를 고정한다. 현재 가이드의 최신 head와 섞지 않는다. |
| 검색 범위 | 이름·지역·종류 탐색으로 시작한다. 전문 검색/오프라인 본문 편집을 새 확정 제품 요구로 추가하지 않는다. |
| 외부 지도 | 목록과 Google Maps 외부 링크를 데이터로 만든다. 실제 지도 API·배경 지도·위치 추적을 넣지 않는다. |
| 화면 검증 | Browser plugin/runtime가 없어 기존 프로젝트 Playwright를 사용한다. 1504×1040 PC와 390×844 모바일을 검사한다. 실기기 검증으로 보고하지 않는다. |

사용자의 자율 진행 위임에 따른 추천 실행이며 개별 제품 정책의 추가 합의가 아니다.

## 최종 검증

- 전체 `npm run check`: **94개 통과**, 타입/프로덕션/PWA 빌드 통과.
- 최종 E2E **26/26 통과**(PC 13 + 모바일 13, 기존 14 + 신규 12). 새 화면은 패키지 추가/두 여행/본문/Fact/표/첨부/과거 조회, 오프라인 기록/정정/계획 변경/모의 초안, 두 탭 충돌, B/L/R, 예약/작업/메모/새 여행, 기존 데이터 전환을 검증했다.
- 첫 실행의 상세 재선택·저장 완료 대기·비활성 오래된 초안 선택은 검사 가정을 수정했다. 추가 기존 전환 E2E에서 발견한 v1 명시적 undefined 선택 필드 호환성은 별도의 tagged 지문으로 수정하고 재통과했다. v2 JSON 계약은 완화하지 않았다.
- 새 화면 E2E에서 브라우저 pageerror/console error·Vite 오류 오버레이 0건, 가로 넘침 없음. PC/모바일 스크린샷을 직접 확인했다. 상세 QA와 증거는 [검증 기록](p02-p05-verification.md)에 있다.
- 실제 SP-FR의 원문/표시/권리·휴대폰 브라우저·전체 백업 복원은 미검증이다.
