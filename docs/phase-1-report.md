## 원천→DB→화면 대응

- **3일·18활동·15이동·숙박 1·10장소**, 콘텐츠 **245개**다. 날짜·시간 정밀도·메뉴·예약 안내·실행 메모/표기·장소 본문·지역/생활/교통·발음/표지·회화 120개를 공통 화면에 연결했다. 숙소·지도·원천 참조와 보충 필드는 날짜별 안내·원천 대조표에서 조회한다.
- **예약 레코드 7 = 코드 5 + 표본 날짜의 XLSX 2**다. 다른 ID를 이름만 보고 합치지 않았다. 같은 제목이 있을 수 있어 코드/통합문서 출처와 locator를 표시한다. 7개의 별도 실제 예약 확정이라는 뜻이 아니다. 같은 지역의 다른 날짜 예약은 XLSX 참조표로 남긴다.
- XLSX **12시트·2,539개 비어 있지 않은 셀**을 제목/열 정의, 표본 날짜·지역/전체 운영 기준의 참조표, 다음 배치 보류로 판정했다. 지역 챕터와 전체 자산 기준도 포함한다. 운동·편집/검수 상태를 실제 활동·방문으로 발명하지 않는다.
- 추출 구조의 leaf **28,266개**: 화면/원천 대조 **5,046**, 형식 메타데이터 **533**, 표본 밖 보류 **22,687**, 미대응 **0**. JSON 배열·XLSX 원문/캐시 구조도 포함한다. 이전 핵심 783필드와 분모가 다르며 전체 여행 이행 완료율이 아니다. 레지스트리는 선택 장소 행만 표시하고 전체 본문은 보류로 기록했다.
- 이번 3일 안의 원천 현장 상태는 **0건**이다. 다른 일자의 메모·방문/체크·예약 수정은 다음 배치 보류다. 새 표본 내 상태가 발견되면 의미 어댑터 없이 완료시키지 않고 차단한다. 실제 방문·확인 시각을 생성하지 않았다.
- 지역 본문의 `<전시명>`은 사라지지 않도록 Markdown AST의 HTML 노드를 텍스트로 표시한다. 코드·자동 링크는 유지하며 HTML을 실행하지 않는다.

## 기술 판단과 발견한 문제

1. **파일 보관:** 새 바이트는 OPFS 불변 파일, DB는 해시·크기·논리 경로를 저장한다. 쓰기→재읽기/해시 확인 후 참조를 게시한다. 기존 DB Blob은 읽기 호환만 유지한다. 실제 브라우저에서 OPFS 미지원 시 조용히 DB로 바꾸지 않는다. 실패 정리·복원 활성화 전 재검증·백업 snapshot 동안 이전 파일 보존을 검사했다.
2. **미디어:** **46파일 = 사진 14그룹의 variant 43 + 관광 지도 3**, **7,732,028 bytes**다. Git blob·tree 크기·manifest SHA-256을 대조했다. 권리자·라이선스·변형·출처·원천의 개인 참고용 근거를 보존했다. 공개 배포 허락을 확인했다는 뜻이 아니다. GitHub 연결 도구의 바이너리 UTF-8 읽기 실패로 고정 raw URL 다운로드를 사용했다.
3. **Fact:** 외부 근거가 없는 값은 원천 commit/locator만 로컬 Evidence로 연결하고 **needs-review·외부 근거 누락**을 표시한다. 이 Evidence는 사실 검증 근거가 아니다. URL·확인일을 만들거나 본문을 조용히 바꾸지 않았다.
4. **실제 백업 실패 해결:** 전체 대응표를 출처 레코드에 넣으면 단일 행 한도를 넘었다. 대응표 **6,727,481 bytes**를 JSON 파일 자산으로 분리했다. DB·보고서는 해시/참조를 보유하고 앱에서 내려받으며 전체 백업에 포함한다. 총 **미디어 46 + 대응표 1 = 47파일**, **14,459,509 bytes**다.
5. **출처 행 예산:** 여러 콘텐츠의 B 기준을 담는 `import_packages`도 약 0.6 MB여서 512 KiB를 넘었다. 일반 행은 512 KiB를 유지하고 이 collection만 **4 MiB**로 구분했다. 준비 전 여유 1 KiB를 포함해 한도를 검사한다. ZIP 전체/해제·명령 한도는 유지했다. 큰 출처의 정확한 복원과 초과 거부를 가상 회귀로 추가했다. 다음 지역이 한도를 넘으면 배치를 다시 설계한다.
6. **격리:** `?review=<이름>`은 고정 prefix의 별도 DB만 선택한다. 평소 DB 이름을 임의로 지정할 수 없다. 사용자 검토 사본에는 자동 검사의 편집 문장·테스트 현장 기록을 넣지 않았다.
