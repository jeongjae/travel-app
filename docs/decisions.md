- 당시 기존 장소 본문 편집·지도·기기 데이터를 질문했으며 후속 답변은 위 결정에 기록했다. 최종 콘텐츠 내부 편집 목표와 초기 이행 수준을 구분한다.

## 구현 선택 · 사용자 합의와 구분

첫 구현 당시 개인/공동 사용·주 기기, 오프라인 범위, AI 실행 위치·승인 정책은 미정이었다. 아래 후속 사용자 답변으로 해당 구현 가정 일부가 확정됐다.

첫 구현 범위: 여러 여행·계획 버전·추가식 실제 기록·검증된 변경안 저장 경로·JSON 변환과 백업. IndexedDB는 기술 구현 선택이며 기기 간 자동 동기화는 첫 MVP 범위에서 제외한다.

## 2026-10-21 · 후속 사용자 결정

- 개인용·모바일 우선.
- 오프라인 일정 조회·현장 기록 저장·백업 파일 제공.
- 앱 안에서 AI 실행, 모든 변경안 확인 후 적용. AI가 조사·검증·초안 저장을 자동으로 수행하되 현재 계획 반영에는 매번 사용자 확인이 필요하다.
- OpenAI API의 새 키 안전 생성을 선택했다. Platform 창에서 키 이름 `Codex`, 프로젝트 `Default project`, 만료 없음(만료 값 미지정)을 선택하고 로컬 `.env.local`의 `OPENAI_API_KEY` 저장 위치를 승인했다.
- 키 발급은 성공했지만 복호화에 필요한 로컬 임시 파일이 후속 실행에서 존재하지 않아 저장 실패. `.env.local` 저장 완료나 API 연결 성공으로 보고하지 않는다. 키를 추가 생성하지 않았으며 재시도 여부를 확인해야 한다. 재시도 시 보안 도우미의 상태 디렉터리를 프로젝트의 무시 경로로 명시하여 실행 간 보존을 보장해야 한다.
- 후속으로 사용자가 새 키 재시도를 승인했다. 무시 경로에 유지한 보안 도우미 상태로 새 `Codex` 키를 발급해 승인된 `.env.local`의 `OPENAI_API_KEY` 저장을 완료했다. 모델 접근 HTTP 200, 가상 여행의 실제 웹 조사·구조화 변경안 생성까지 검증했다. 첫 저장 실패 키는 별도 폐기 필요이며 자동으로 폐기했다고 보고하지 않는다.
- 서버 실행 위치·호스팅·공개 범위·모델/예산은 아직 확정하지 않았다. 개인 여행 데이터 전송 범위는 실제 호출 경로에서 설명한다.

## AI 첫 구현 기술 선택

- 로컬 Node HTTP 서버와 OpenAI Responses API를 연결한다. 개발 5173/프로덕션 미리보기 4173에서 `/api`를 loopback 8787로 프록시한다. 서버만 `.env.local`을 읽는다. 공개 배포 결정은 포함하지 않는다.
- 모델은 웹 검색·구조화 출력을 지원하고 실제 키로 접근을 확인한 `gpt-5.4-mini`를 초기 구현 기본값으로 선택했다. `OPENAI_MODEL`로 변경 가능하며 사용자 고정 모델 합의로 기록하지 않는다.
- 실제 웹 검색으로 수집한 URL만 근거에 허용한다. 자동 수집을 독립 사실 검증으로 과장하지 않고 AI 근거는 `unverified`로 저장한다.
- 웹 조사 1단계 뒤 구조화 작성 최대 2회. 도메인 검증 피드백만 자동 보정하며 인증/한도 오류는 즉시 실패한다. 작업 ID 중복 호출은 재과금하지 않는다. 완료 결과 조회·브라우저 재로드는 유료 실행을 새로 만들지 않는다.
- 작업 상태·결과·입력 fingerprint를 로컬 파일에 원자 저장하고 재시작 때 진행 작업을 interrupted로 표시한다. 원본 여행 전체는 서버 작업 파일에 저장하지 않는다. 생성 결과에는 여행 정보가 남을 수 있다.
- 사용자 확인은 기존 `repository.decide` 경로로만 현재 계획을 바꾼다. 작업 생성·조회·초안 저장이 승인으로 취급되지 않는다.

## 기술 선택 · 첫 구현

| 선택 | 이유 | 검토한 대안 |
|---|---|---|
| TypeScript + React + Vite | 다중 여행·기록·변경안 화면의 상태를 구성하고, 명시적 타입과 정적 배포 가능한 앱 셸 제공 | 기존 vanilla JS 유지: 상태·스키마 검증을 새로 체계화해야 함. Next.js: 현 단계 SSR 필요가 없고 서버 운영을 늘림 |
| Dexie / IndexedDB | 오프라인 구조화 저장, 원자적 트랜잭션, 복수 탭 변경 감지 | localStorage: 트랜잭션과 용량 제약. 서버 PostgreSQL: 계정·동기화 요구 확정 후 도입 |

| Temporal polyfill | IANA 시간대, 자정 경계, DST 모호/없는 현지 시각 처리 | Date 문자열 추정은 기기 시간대 의존 위험 |
| Vitest + fake-indexeddb, Playwright | 도메인 보존·충돌과 실제 브라우저 재시작·오프라인 검증 | 화면 스모크만으로 데이터 보존을 입증할 수 없음 |
| Vite PWA 플러그인 | 빌드 산출물에서 앱 셸 목록을 자동 생성 | 수동 서비스워커 파일 목록은 해시 파일 누락 위험 |
